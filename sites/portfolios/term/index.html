решения

  • neural-archive site
    сайт-архив флеш-работ с живым воспроизведением через ruffle. каталог, фильтры, загрузка .swf перетаскиванием, помощник. движок и шрифты рядом со страницей — работает без сети.
    $ open https://zagent.do.am/index.html
  • ada-telegram-bot bot
    помощница для чатов. откликается на «ада» в любом написании и только как отдельное слово. в беседе вмешивается в каждое десятое сообщение. помнит ход разговора. стдлиб.
    $ open https://t.me/adaweffeBot
  • zradio win
    радиоклиент: окно и консоль, 37 станций, пинг доступности. окно прячется, музыка играет в отдельном процессе wmp. лаунчер .exe собирается из c# без зависимостей.
  • swf-generator fmt
    настоящие несжатые .swf из python: заголовок, сцена, теги, кадры. демо весят 800–4000 байт. главные грабли формата — выравнивание после rect и порядок байт — закрыты.
  • bot-proxy sec
    ключ остаётся на машине. наружу — один маршрут с проверкой источника и лимитом запросов. агент на 127.0.0.1 наружу не выпускается.
  • zagent agent
    очередь задач, файлы, воркспейсы, встроенные модели, телеграм-боты, пинги, диагностика. ключи только на диске.
    $ wget zagent.zip — готовится

ключи

все адреса официальные. бесплатно, без карты.

  • openrouter.ai/keys — много моделей, есть :free
  • console.groq.com/keys — быстро, щедрый лимит
  • console.mistral.ai/api-keys — пробный ключ сразу
  • build.nvidia.com — бесплатно, нужен аккаунт
  • t.me/BotFather — токен бота

ключ в браузере принадлежит не тебе, а тому, кто открыл страницу. держите ключ на сервере.

что стоило дороже всего

  • тело запроса читать до проверок. иначе при отказе клиент получает разрыв соединения вместо «слишком много вопросов», и в браузере это «ошибка сети».
  • порядок байт. биты внутри байта от старшего, числа — от младшего. номер персонажа 1 читался как 256, и файл был «почти правильным», пока не заиграл.
  • длинный опрос там, где его рвут. прокси хостинга держит соединение три секунды. бот был молчалив при полностью рабочей защите — просто ждал дольше, чем можно.

сборка у себя

# 1. нужен только python 3.9+, ничего доустанавливать не надо
python --version

# 2. скопировать файл и запустить
python zradio.py            # окно со станциями
python ada_bot.py           # телеграм-помощница
python make_demo_swf.py     # собрать три демо .swf

# 3. ключи — в config.json рядом со скриптом, не в код
#    файл в .gitignore добавлен осознанно

# 4. бота в группу: @BotFather -> /setprivacy -> Disable
#    иначе в беседе он увидит только реплики с упоминанием

# 5. сайт: папка ruffle/ рядом с index.html — и он не зависит от сети
