# scraper-basic

Разовый сбор страницы в CSV на стандартной библиотеке. Без `requests`, без
`beautifulsoup4`, без сборки.

## Запуск

```
python scrape.py https://example.com            # → out.csv
python scrape.py https://example.com links.csv   # свой файл
python scrape.py https://example.com --limit 20  # ограничить число ссылок
```

Зависимостей нет — стандартная библиотека.

## Когда применять

- Нужен разовый сбор: заголовок и ссылки со страницы в CSV.
- Сайт отдаёт разметку сразу, без JavaScript.
- Не хочется ставить зависимости ради одной страницы.

## Когда НЕ применять

- **Сайт рендерится через JavaScript.** Это главная причина. Скрипт увидит
  пустоту и запишет её в CSV, не сказав почему. Бери `../scraper-playwright`.
- Нужно идти вглубь по ссылкам: здесь ровно одна страница.
- Нужна JavaScript-страница с авторизацией.
- Сайт требует cookie или заголовок `Referer`.

## Как проверить, подходит ли этот скрипт

Открой страницу, выключи JavaScript и посмотри, есть ли текст. Если пусто —
нужен браузер, а не парсер.

## Что показывает этот файл

| Решение | Зачем |
|---|---|
| честный `User-Agent` со ссылкой | владелец сайта может связаться и отличит нас от спама |
| пауза между запросами | сайт не тратится зря |
| повтор с нарастающей паузой | переживает кратковременную ошибку, не долбит |
| 404 и 410 без повторов | их повтор бессмыслен |
| `convert_charrefs=True` | `&amp;` не портит текст ссылки |
| одна точка входа `scrape()` | её можно покрыть тестами, не запуская сеть |
| битая страница → строка в отчёте, а не падение | один отказ не губит весь сбор |

## Почему не подделываем браузер

Строка `Mozilla/5.0 ...` была бы подделкой: владелец сайта не найдёт нас для
связи и не отличит от спамера. Честный `User-Agent` стоит чуть больше блокировок
и экономит отношения с владельцами сайтов.

## Чего здесь нет намеренно

- Обхода очереди и возобновления: скрипт одноразовый.
- Ротации прокси и управления темпом: для этого нужен отдельный инструмент.
- `robots.txt`: **если сайт запрещает обход, этот скрипт не должен запускаться.**
  Проверяйте `robots.txt` сами; библиотека не заменяет разрешение владельца.

## Если адаптируешь

Сохраните паузу и честный `User-Agent`. Если нужен обход вглубь — добавьте
очередь и счётчик, а не убирайте паузу: без неё сайт получит столько запросов,
сколько выдержит, и заблокирует не вас, а себя.
