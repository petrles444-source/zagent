# Библиотека эталонов

Это то, что агент читает **до** того, как начнёт писать с нуля. Не свалка
примеров: каждый эталон отвечает на узкий вопрос и говорит, когда его
применять **и когда не применять**.

## Правила пополнения

1. **Эталон меньше 500 строк.** Если больше — это уже проект, а не образец.
   Дробите.
2. **Самодостаточность.** Эталон запускается после копирования в чистую папку.
   Если нужен соседний файл из библиотеки — эталон не самодостаточен.
3. **README обязателен.** Три раздела: когда применять, когда **не**
   применять, что внутри. Второй важнее первого: именно он спасает от
   натягивания неподходящего эталона.
4. **Запись в `INDEX.yaml` обязательна.** Папка без записи в индексе агент не
   найдёт — он читает индекс, а не обходит дерево.
5. **Лицензия и источник.** Своё — `license: своё`. Чужое — ссылка и лицензия
   обязательно, иначе эталон нельзя переносить в проект.
6. **Эталон должен быть честным.** Если в нём есть обходной путь «на скорую
   руку» — вычистите: агент скопирует и обходной путь тоже.

## Как агент это видит

Агент получает список из `INDEX.yaml` в промпт. Только подсказка из задания
разворачивается подробно (`когда` / `когда НЕ`), остальное — одной строкой на
эталон. Так индекс остаётся дешёвым по токенам.

Эталон подкладывается в песочницу копией, а не ссылкой: агент может переписать
его под задачу, и библиотека от этого не портится.

## Как оценивается использование

Не по упоминанию названия папки, а по сходству текста: `difflib` сравнивает
файлы эталона с файлами результата, берётся лучшая пара для каждого файла
эталона. Порог — `0.35`.

`reinvented_wheel` — это **метка для разбора**, а не приговор. Если задача была
нестандартной и эталон слабо подходил, метка врёт. Смотрите, растёт ли таких
прогонов, и правьте индекс, а не агента.

## Структура

```
ref/
├── INDEX.yaml               ← машинный индекс, единственный вход для агента
├── README.md                ← этот файл
├── landing/                 ← одностраничники, статика без сборки
├── multipage/               ← несколько страниц, формы, база
├── desktop/                 ← программы с окном
├── scripts/                 ← разовые скрипты: парсинг, автоматизация
├── vision/                  ← разбор изображений
└── meta/
    ├── anti-patterns.md     ← чего агент делать не должен
    └── eval-rubrics.md      ← как оценивать результат
```
