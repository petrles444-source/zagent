# snake

Змейка на canvas. Открыл `index.html` — играет, без сборки и без зависимостей.

## Когда применять

- Нужна простая игра для примера, обучения или проверки canvas.
- Нужна логика с пошаговым циклом: змейка — самая маленькая игра, где
  столкновения, скорость и счёт действительно интересны.
- Нужно показать, как устроен игровой цикл в браузере.

## Когда НЕ применять

- **Нужно управление свайпами на телефоне** — здесь только клавиши. Это самая
  частая претензия, и она не решена.
- Нужны уровни, препятствия, несколько жизней — здесь чистая классика.
- Нужны уровни, сохранение процесса между вкладками, сетевая игра.
- Нужна физика или спрайты → это другая задача.

## Что показывает этот файл

| Решение | Почему именно так |
|---|---|
| **очередь поворотов** | при быстрых нажатиях «вверх» и «влево» без очереди змейка разворачивается в себя и умирает на ровном месте |
| **`requestAnimationFrame` + накопленное время** | два таймера расходятся по кадрам: на 144 Гц игра шла бы вдвое быстрее |
| **ограничение очереди двумя** | больше нажатий за ход всё равно не сыграет, но создаёт задержку ввода |
| **хвост отнимается до проверки столкновения** | на бывшую клетку хвоста шагнуть можно — змейка её освободила |
| **`accum` сбрасывается при долгом простое** | свёрнутая вкладка иначе «догоняла» бы пропущенное время пачкой шагов |
| **`localStorage` в `try`** | приватный режим запрещает хранилище; игра обязана работать и без рекорда |
| **логика отдельно от DOM** | `tick()` не трогает отрисовку, поэтому проверяется без браузера |

## Порядок проверки столкновения

Самая частая ошибка — проверить столкновение по всему телу **до** отнимания
хвоста. Тогда змейка не может сделать ход «в хвост» при развороте длиной 1–2,
и игра вязнет на ровном месте. Правильный порядок:

1. посчитать следующую голову;
2. отнять хвост из тела;
3. проверить столкновение с оставшимся;
4. добавить голову.

## Чего здесь нет намеренно

- Свайпов. Управление с клавиатуры на телефоне не работает, и README это
  признаёт, а не делает вид, что всё в порядке.
- Уровней и препятствий.
- Звука.

## Если адаптируешь

Сохраните очередь поворотов и порядок отнимания хвоста — это те два места,
где змейка ломается в первый же час игры. Всё остальное можно менять
свободно.
