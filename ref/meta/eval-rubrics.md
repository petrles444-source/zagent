# Как оценивать результат

Две шкалы: **функциональная** (работает или нет) и **процессная** (как
получено). Смешивать их нельзя — иначе нельзя понять, что чинить.

## Функциональная часть

| Проверяем | Признак провала |
|---|---|
| запускается | команда из README даёт ошибку |
| делает заявленное | сценарий из задания не сходится |
| адаптив | горизонтальная прокрутка на узком экране |
| валидация | пустой ввод проходит |
| обработка ошибок | необработанное исключение на пустом ответе |
| безопасность | пароль в открытом виде, SQL склейкой |

## Процессная часть

| Признак | Как измерить |
|---|---|
| использовал эталон | сходство текста с библиотекой (`bench.refbook.similarity`) |
| дошёл до конца | агент сам объявил задачу выполненной |
| уложился в лимит | длительность против `timeout_minutes` |
| не раздул | строк больше, чем нужно, без причины |
| не натянул неподходящее | эталон взят, но задача нестандартная |

## Про `reinvented_wheel`

Метка **не** означает «плохой агент». Она означает одно из трёх:

1. агент не знает про библиотеку → поправить промпт;
2. эталон плохо индексирован → поправить `INDEX.yaml`;
3. задача была нестандартной → метка врёт, поправить задание.

Если третье повторяется много раз, это не метка врёт, а индекс врёт: значит,
под нестандартные задачи эталонов действительно не хватает.

## Как читать процент

Процент **не** ответ на вопрос «хорошо ли». 60% может означать:

- 60% требований не выполнено — плохо;
- выполнено всё важное, не выполнено косметика — нормально;
- веса расставлены неверно и 20% веса досталось на проверку «есть alt у
  картинок» — проблема в задании.

Смотрите разбивку по проверкам, а не итог.

## Когда пора менять библиотеку

Повторилось три раза одно и то же `reinvented_wheel` на задачах одного типа →
добавьте эталон на этот тип. Это дешевле, чем в сотый раз объяснять агенту в
промпте, что такое «простой одностраничник».

Повторились провалы одной проверки в трёх заданиях подряд → скорее всего
проверка неверная, а не агент неправ. Проверьте её на эталоне: если эталон её
не проходит, виновата проверка.
