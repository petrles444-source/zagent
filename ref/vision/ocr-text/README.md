# ocr-text

Извлечение текста из картинки **и способ измерить, насколько точно он прочитан**.

## Когда применять

- Нужен текст из скриншота, фотографии или скана.
- Важно не «получить текст», а понимать, можно ли ему доверять.
- Нужно сравнить два OCR-движка на своих картинках.

## Когда НЕ применять

- **Нужен разбор структуры интерфейса по скриншоту**: где кнопки, где поля,
  где таблица. OCR даст текст, но не даст прямоугольники и роли. Это другая
  задача, и она этим файлом не решается.
- Нужен текст с рукописного ввода на сложных фрагментах: порог 20% — это
  «примерно», а не «годно для ввода в систему».
- Нужно читать PDF: сначала достать страницы в картинки (`pdftoppm`).
- Нужно читать язык, для которого нет модели Tesseract.

## Запуск

```
pip install pillow pytesseract
choco install tesseract                      # Windows
sudo apt install tesseract-ocr tesseract-ocr-rus   # Ubuntu

python ocr.py photo.png
python ocr.py shot.png --gt samples/02_table.gt.txt --kind table
python ocr.py --make-samples --out samples
```

Без движка скрипт объясняет, что делать, и вернёт код `2`. Это сознательно:
«молча ничего не нашёл» хуже, чем «движок не установлен».

## Пороги точности

| Тип картинки | Допустимый CER | Почему так |
|---|---:|---|
| код | 2% | символы отличаются, код перестаёт работать |
| таблица | 5% | важны числа и порядок колонок |
| диалог | 8% | читаемый текст, допустима опечатка |
| фотография | 15% | шум, поворот, перспектива |
| рукописный | 20% | почерк нестабилен |

## Что показывает этот файл

| Решение | Зачем |
|---|---|
| `normalize()` перед сравнением | без неё оценка врёт на проценты из-за пробелов |
| CER **и** WER | ошибка на 3% текста может быть 30% от всех слов |
| `psm 6` для скриншотов | автоподбор режима заметно хуже на код�� и таблицах |
| увеличение до 1400 px | Tesseract рассчитан примерно на 300 dpi |
| `autocontrast` | серый фон скриншота ломает порог |
| движок не найден → код 2 | результат «ничего не распознано» отличается от «нечем было» |
| `--make-samples` | эталоны рисуются, а не качаются: оценка не зависит от сети |

## Почему CER, а не «похоже на глаз»

Глаз не замечает пропавший `0` в числе `100`. CER считает символы и
показывает: `ошибка 3.4%` и `провал нормы 2%` — это факт, который можно
обсуждать. «Ну вроде похоже» — нет.

## Чего здесь нет намеренно

- **Облачного OCR.** Локально, без отправки чужих скриншотов в интернет.
- Распознавания формул и таблиц в готовом виде: `--psm 6` даст текст, но не
  структуру.
- `easyocr` и `paddleocr`: точнее на рукописном и сложных фонах, но тянут
  PyTorch. Ставьте, если Tesseract не тянет.

## Если адаптируешь

Меняйте `--psm` под тип картинки и пороги под свой домен. Не выбрасывайте
`normalize`: без неё оценка сравнивает пробелы, а не содержание.
