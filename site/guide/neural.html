1. ВВЕДЕНИЕ В НЕЙРОННЫЕ СЕТИ

Искусственные нейронные сети (ИНС) — это вычислительные модели, вдохновлённые структурой и функционированием биологического мозга. Они состоят из interconnected processing units, называемых нейронами или узлами, которые организованы в слои и обучаются распознавать закономерности в данных[reference:0].

1.1. Что такое нейронная сеть

Нейронная сеть — это математическая модель, которая преобразует входные данные в выходные через последовательность слоёв. Каждый слой состоит из нейронов, каждый из которых вычисляет взвешенную сумму входов и применяет нелинейную функцию активации[reference:1].

1.2. Биологическая аналогия

Биологический нейрон получает сигналы через дендриты, обрабатывает их в теле клетки (соме) и передаёт результат через аксон к синапсам. Искусственный нейрон моделирует этот процесс: входы (x) умножаются на веса (w), суммируются, добавляется смещение (b), и результат проходит через функцию активации[reference:2].

1.3. Классификация по типу обучения
Тип обученияОписаниеПримеры

Глубокое обучение (Deep Learning) — это подмножество машинного обучения, использующее нейронные сети с множеством слоёв (глубокие сети) для автоматического извлечения иерархических признаков из данных[reference:3].

3. ИСКУССТВЕННЫЙ НЕЙРОН
3.1. Математическая модель

Искусственный нейрон вычисляет взвешенную сумму входов, добавляет смещение и применяет функцию активации:

y = f( Σᵢ wᵢ·xᵢ + b )

где:

xᵢ
входные сигналы (признаки)
wᵢ
веса (обучаемые параметры)
b
смещение (bias)
f
функция активации
y
выход нейрона
3.2. Слои нейронной сети
СлойОписаниеФункция
ВходнойПринимает исходные данныеПередача признаков
СкрытыеПромежуточные слоиИзвлечение иерархических признаков
ВыходнойФинальный слойФормирование предсказания
3.3. Типы нейронов
ТипОсобенности

ReLUmax(0,x), популярен в скрытых слоях

4. ФУНКЦИИ АКТИВАЦИИ

Функции активации вводят нелинейность в нейронную сеть, что позволяет ей аппроксимировать сложные нелинейные зависимости. Без них многослойная сеть была бы эквивалентна однослойной линейной модели[reference:4].

4.1. Основные функции активации
Sigmoid (Логистическая)
σ(x) = 1 / (1 + e⁻ˣ)

Диапазон: (0, 1) • Проблемы: затухание градиента, выход не центрирован

Tanh (Гиперболический тангенс)
tanh(x) = (eˣ − e⁻ˣ) / (eˣ + e⁻ˣ)

Диапазон: (−1, 1) • Лучше sigmoid: центрирован относительно нуля

ReLU (Rectified Linear Unit)
ReLU(x) = max(0, x)

Диапазон: [0, ∞) • Плюсы: быстро, решает затухание • Минус: "мёртвые нейроны"

Leaky ReLU
LeakyReLU(x) = max(αx, x), α = 0.01

Решает: проблему мёртвых нейронов

ELU (Exponential Linear Unit)
ELU(x) = { x, x > 0; α(eˣ − 1), x ≤ 0 }
Swish / SiLU
Swish(x) = x · σ(x)

Найдена автоматическим поиском, используется в современных сетях

Mish
Mish(x) = x · tanh(softplus(x))
Softmax
Softmax(xᵢ) = eˣⁱ / Σⱼ eˣʲ

Используется в выходном слое для многоклассовой классификации

4.2. Сравнительная таблица
ФункцияДиапазонПлюсыМинусы
Sigmoid(0, 1)Вероятностная интерпретацияЗатухание градиента
Tanh(−1, 1)ЦентрированаЗатухание градиента
ReLU[0, ∞)Быстрая, решает затуханиеМёртвые нейроны
Leaky ReLU(−∞, ∞)Решает мёртвые нейроныНужен подбор α
ELU(−α, ∞)Близка к нулюДороже вычисления
Swish(−∞, ∞)Гладкая, хорошая точностьДороже
Softmax(0, 1)МногоклассоваяТолько выходной слой
Для скрытых слоёв современных сетей по умолчанию используется ReLU или его варианты. Для выходного слоя: sigmoid (бинарная), softmax (многоклассовая), linear (регрессия).
5. ФУНКЦИИ ПОТЕРЬ

Функция потерь (loss function) измеряет разницу между предсказанием модели и истинным ответом. Цель обучения — минимизировать эту функцию.

5.1. Основные функции потерь
ФункцияФормулаПрименение
MSEΣ(yᵢ − ŷᵢ)² / nРегрессия
MAEΣ|yᵢ − ŷᵢ| / nРегрессия, устойчива к выбросам
Cross-Entropy−Σ yᵢ·log(ŷᵢ)Классификация
Binary CE−[y·log(ŷ) + (1−y)·log(1−ŷ)]Бинарная классификация
Hingemax(0, 1 − y·ŷ)SVM, margin-классификация
Huberкомбинация MSE и MAEРегрессия с выбросами
KL-DivergenceΣ p·log(p/q)Распределения, VAE
Focal Loss−α(1−ŷ)ᵞ·log(ŷ)Дисбаланс классов
Для многоклассовой классификации используйте Cross-Entropy с Softmax. Для регрессии — MSE (если нет выбросов) или Huber.
6. МЕТОДЫ ОПТИМИЗАЦИИ

Оптимизаторы определяют, как обновляются веса сети на основе градиентов функции потерь. Это ключевой компонент обучения[reference:5].

6.1. Градиентный спуск
w := w − η · ∇L(w)

где η — скорость обучения (learning rate), ∇L — градиент потерь

6.2. Варианты градиентного спуска
МетодОписание
Batch GDОбновление по всему датасету (стабильно, медленно)
SGDОбновление по одному примеру (быстро, шумно)
Mini-batch GDКомпромисс: батчи 32–512 (стандарт)
6.3. Адаптивные оптимизаторы
Momentum
v := β·v + ∇L; w := w − η·v

Накопление импульса для ускорения сходимости

Nesterov Momentum

Улучшенный momentum с "опережающим" градиентом

Adagrad
w := w − η·∇L / √(G + ε)

Адаптивная скорость для каждого параметра

RMSprop

Экспоненциальное сглаживание квадратов градиентов

Adam (Adaptive Moment Estimation)
m := β₁·m + (1−β₁)·∇L; v := β₂·v + (1−β₂)·∇L²

Комбинация momentum + RMSprop. Наиболее популярный оптимизатор. Исследования показывают, что Adam достигает наивысшей точности (91% на структурированных данных)[reference:6].

AdamW

Adam с правильной реализацией weight decay (L2-регуляризации)

Lion

Новый оптимизатор от Google, использует только знак градиента

6.4. Сравнение оптимизаторов
ОптимизаторСкоростьСтабильностьПамять
SGDМедленноВысокаяНизкая
SGD + MomentumСреднеВысокаяНизкая
RMSpropБыстроСредняяСредняя
AdamБыстроВысокаяСредняя
AdamWБыстроВысокаяСредняя
LionБыстроВысокаяВысокая
Стратегия обучения: Adam для начального этапа (быстрая сходимость) → SGD с momentum для тонкой настройки (лучшая генерализация). Гибридный подход показал высокую эффективность[reference:7].
7. ОБРАТНОЕ РАСПРОСТРАНЕНИЕ

Алгоритм обратного распространения ошибки (backpropagation) — основной метод обучения нейронных сетей. Он вычисляет градиенты функции потерь по всем весам с использованием цепного правила дифференцирования[reference:8].

7.1. Алгоритм
Шаг 1. Forward pass
Прямой проход: вычисление выходов слоёв
Шаг 2. Loss
Вычисление функции потерь
Шаг 3. Backward pass
Обратный проход: вычисление градиентов
Шаг 4. Update
Обновление весов: w := w − η·∇L
7.2. Цепное правило
∂L/∂w₁ = ∂L/∂y · ∂y/∂z · ∂z/∂w₁
7.3. Проблемы
ПроблемаПричинаРешение
Затухание градиентаМного слоёв, сигмоидыReLU, residual connections, LSTM
Взрыв градиентаБольшие весаGradient clipping, нормализация
Мёртвые нейроныReLU с отрицательными входамиLeaky ReLU, ELU
8. РЕГУЛЯРИЗАЦИЯ И НОРМАЛИЗАЦИЯ

Регуляризация предотвращает переобучение (overfitting), когда модель запоминает обучающие данные вместо изучения общих закономерностей[reference:9].

8.1. Методы регуляризации
L1 / L2 регуляризация
L_total = L + λ·Σ|w| (L1) или L + λ·Σw² (L2)

Штраф за большие веса. L1 → разреженность, L2 → гладкость

Dropout

Случайное "отключение" нейронов с вероятностью p во время обучения. Предотвращает совместную адаптацию нейронов[reference:10].

# PyTorch
nn.Dropout(p=0.5)

# Keras
layers.Dropout(0.5)
Batch Normalization

Нормализация активаций каждого слоя: вычитание среднего, деление на стандартное отклонение. Ускоряет обучение, снижает чувствительность к инициализации[reference:11].

# PyTorch
nn.BatchNorm2d(num_features)

# Keras
layers.BatchNormalization()
Layer Normalization

Нормализация по признакам, а не по батчу. Используется в трансформерах

Early Stopping

Остановка обучения, когда валидационная ошибка начинает расти

Data Augmentation

Искусственное расширение обучающей выборки: повороты, сдвиги, шум

8.2. Сравнение методов
МетодЭффектСложностьКогда использовать
L2Сглаживание весовНизкаяВсегда (базовый)
DropoutАнсамблированиеНизкаяБольшие полносвязные слои
Batch NormУскорение + стабильностьСредняяCNN, глубокие сети
Layer NormСтабильностьСредняяRNN, Transformer
Early StoppingПредотвращение переобученияНизкаяВсегда
9. ПОЛНОСВЯЗНЫЕ СЕТИ (FFNN / MLP)

Feedforward Neural Network — базовая архитектура, где данные проходят от входа к выходу без циклов. Многослойный перцептрон (MLP) — классический пример[reference:12].

9.1. Структура
Input → [Linear → Activation] × N → Output
9.2. Универсальная аппроксимация

Теорема об универсальной аппроксимации: сеть с одним скрытым слоем достаточной ширины может аппроксимировать любую непрерывную функцию на компактном множестве[reference:13].

9.3. Пример на PyTorch
import torch.nn as nn

class MLP(nn.Module):
    def __init__(self, input_size, hidden_size, num_classes):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(input_size, hidden_size),
            nn.ReLU(),
            nn.Linear(hidden_size, hidden_size),
            nn.ReLU(),
            nn.Linear(hidden_size, num_classes)
        )
    
    def forward(self, x):
        return self.net(x)
9.4. Когда использовать
ЗадачаПодходит
Табличные данныеДа
ИзображенияНет (CNN лучше)
ПоследовательностиНет (RNN/Transformer)
Простые задачиДа
10. СВЁРТОЧНЫЕ СЕТИ (CNN)

Convolutional Neural Networks — специализированная архитектура для обработки данных с пространственной структурой (изображения, видео). Используют свёртки для извлечения локальных признаков[reference:14].

10.1. Ключевые компоненты
СлойФункция
Conv2DСвёртка: применение фильтров к входу
PoolingУменьшение размерности (max/avg)
FlattenПреобразование в вектор
DenseПолносвязный слой для классификации
10.2. Свёртка
(f * g)(t) = Σ f(τ)·g(t − τ)

Фильтр (ядро) скользит по входу, вычисляя скалярное произведение. Позволяет обнаруживать локальные признаки (края, текстуры).

10.3. Популярные архитектуры
АрхитектураГодОсобенность
LeNet-51998Первая CNN для MNIST
AlexNet2012ReLU, dropout, GPU
VGG2014Глубокие 3×3 свёртки
ResNet2015Skip connections, 152 слоя
Inception2014Multi-scale, 1×1 свёртки
EfficientNet2019Compound scaling
10.4. Пример на PyTorch
class CNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv = nn.Sequential(
            nn.Conv2d(3, 32, 3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),
            nn.Conv2d(32, 64, 3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),
        )
        self.fc = nn.Linear(64 * 8 * 8, 10)
    
    def forward(self, x):
        x = self.conv(x)
        x = x.view(x.size(0), -1)
        return self.fc(x)
11. РЕКУРРЕНТНЫЕ СЕТИ (RNN / LSTM / GRU)

Recurrent Neural Networks — архитектуры для обработки последовательностей. Имеют "память" о предыдущих состояниях[reference:15].

11.1. RNN
hₜ = tanh(Wₓ·xₜ + Wₕ·hₜ₋₁ + b)

Проблема: затухание/взрыв градиента на длинных последовательностях

11.2. LSTM (Long Short-Term Memory)

Решение проблемы долгосрочных зависимостей через механизм гейтов:

ГейтФункция
Forget gateЧто забыть из памяти
Input gateЧто записать в память
Output gateЧто выдать на выход
11.3. GRU (Gated Recurrent Unit)

Упрощённая версия LSTM с двумя гейтами: reset и update. Меньше параметров, быстрее обучение. Менее чувствительна к гетерогенности данных[reference:16].

zₜ = σ(Wₓ·xₜ + Wₕ·hₜ₋₁ + b)
11.4. Сравнение RNN, LSTM, GRU
МодельПараметрыСкоростьДолгосрочная память
RNNМалоБыстроПлохо
LSTMМногоМедленноОтлично
GRUСреднеСреднеХорошо
11.5. Пример на PyTorch
class RNNModel(nn.Module):
    def __init__(self, input_size, hidden_size, num_layers=2):
        super().__init__()
        self.lstm = nn.LSTM(
            input_size, hidden_size, num_layers, 
            batch_first=True, bidirectional=True
        )
        self.fc = nn.Linear(hidden_size * 2, 1)
    
    def forward(self, x):
        out, (h, c) = self.lstm(x)
        return self.fc(out[:, -1, :])
12. ТРАНСФОРМЕРЫ И ВНИМАНИЕ

Transformer — архитектура, основанная исключительно на механизме внимания (attention), без рекуррентности. Революция в NLP и не только[reference:17].

12.1. Механизм внимания (Self-Attention)

Внимание определяет, насколько сильно каждый элемент последовательности влияет на другие. Используются три вектора: Query (Q), Key (K), Value (V)[reference:18].

Attention(Q, K, V) = softmax(Q·Kᵀ / √dₖ) · V
12.2. Multi-Head Attention

Несколько голов внимания (8–16) параллельно учатся различным представлениям. Выходы конкатенируются и проецируются[reference:19].

12.3. Архитектура Transformer
КомпонентФункция
EncoderОбработка входа, создание представлений
DecoderГенерация выхода
Multi-Head AttentionПараллельное внимание
Positional EncodingИнформация о порядке элементов

class TransformerBlock(nn.Module):
    def __init__(self, d_model=512, nhead=8):
        super().__init__()
        self.attn = nn.MultiheadAttention(d_model, nhead)
        self.norm1 = nn.LayerNorm(d_model)
        self.ff = nn.Sequential(
            nn.Linear(d_model, 2048),
            nn.ReLU(),
            nn.Linear(2048, d_model)
        )
        self.norm2 = nn.LayerNorm(d_model)
    
    def forward(self, x):
        attn_out, _ = self.attn(x, x, x)
        x = self.norm1(x + attn_out)
        ff_out = self.ff(x)
        return self.norm2(x + ff_out)
13. ГЕНЕРАТИВНЫЕ СЕТИ (GAN, VAE)
13.1. GAN (Generative Adversarial Networks)

Две сети соревнуются: генератор создаёт подделки, дискриминатор отличает их от реальных. В процессе обучения обе улучшаются[reference:20].

Generator
Создаёт данные из шума
Discriminator
Различает реальное и сгенерированное

13.3. VAE (Variational Autoencoder)

Генеративная модель, обучающаяся на латентном пространстве. Использует KL-дивергенцию для регуляризации[reference:21].

14. АВТОЭНКОДЕРЫ

Автоэнкодер — сеть, обучающаяся восстанавливать входные данные через узкое "бутылочное горлышко" (латентное пространство). Используется для понижения размерности, денойзинга, аномалий[reference:22].

Input → Encoder → Latent → Decoder → Output
