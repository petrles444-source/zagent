1. АВТОРИЗАЦИЯ И ACCESS_TOKEN

Для работы со всеми методами API необходимо передавать в запросе access_token — специальный ключ доступа[reference:0]. После успешной авторизации приложения браузер пользователя перенаправляется по адресу redirect_uri, указанному при открытии диалога авторизации[reference:1].

Типы авторизации
ТипОписаниеГде применяется
VK ID / OAuth 2.0Основной механизм аутентификации, пришёл на замену старому OAuth[reference:2]Веб-приложения, Standalone
Implicit FlowТокен возвращается напрямую в URL после авторизацииКлиентские приложения
Authorization Code FlowСервер обменивает код на токен через id.vk.ru/oauth2/auth[reference:3]Серверные приложения
Прямая авторизацияПолучение токена по логину и паролю[reference:4]Устаревший метод, не рекомендуется

4. КОДЫ ОШИБОК

API возвращает коды ошибок в формате error_code + error_msg. Ниже — основные коды, которые необходимо обрабатывать в production-коде[reference:12].

КодСообщениеДействие
1Произошла неизвестная ошибкаПовторить запрос позже
2Приложение выключеноВключить в настройках или использовать test_mode=1
3Передан неизвестный методПроверить название метода
4Неверная подписьПроверить secret / client_secret
5Авторизация не удаласьПроверить схему авторизации и токен
6Слишком много запросов в секундуУвеличить интервал или использовать execute
7Нет прав для действияПроверить scope через account.getAppPermissions
8Неверный запросПроверить синтаксис и параметры
9Слишком много однотипных действийСократить число обращений
10Внутренняя ошибка сервераПовторить запрос позже
14Captcha neededОбработать капчу через VK ID Captcha SDK
15Доступ запрещёнПроверить идентификаторы и права
16Требуется HTTPSПереключиться на безопасное соединение
17Требуется валидацияПеренаправить пользователя на страницу валидации
Ошибка с Captcha (код 14)

Если пользователь слишком часто выполняет действие, API возвращает ошибку с кодом 14 и текстом "Captcha needed". В ответе также приходит параметр redirect_uri — ссылка для инициализации сессии капчи, содержащая токен сессии[reference:13].

{
  "error": {
    "error_code": 14,
    "error_msg": "Captcha needed",
    "redirect_uri": "https://id.vk.com/not_robot_captcha?domain=vk.com&session_token=...",
    "remixstlid": 9069780796616521905
  }
}
Обработка капчи без redirect_uri (через captcha_sid и captcha_img) больше не поддерживается. Используйте VK ID Captcha SDK[reference:14].
Ошибка 1051 — Method not available

Возникает при попытке вызвать метод, недоступный для текущего типа профиля или токена. Например, wall.post может вернуть ошибку 1051, если токен несовместим с методом[reference:15].

6. CALLBACK API

Callback API — инструмент отслеживания активности, при котором передача данных инициируется сервером VK после возникновения события, на которое оформлена подписка[reference:22].

Настройка Callback API
1. Раздел
Сообщество → Управление → Работа с API → Callback API
2. Версия API
5.199 (или актуальная стабильная)[reference:23]
3. URL сервера
https://YOUR_DOMAIN/api/vk/callback[reference:24]
4. Секретный ключ
Задаётся в .env как VK_CALLBACK_SECRET[reference:25]
5. Подтверждение
VK пришлёт {"type":"confirmation"} — вернуть строку подтверждения[reference:26]
6. События
Включить типы: message_new, message_allow, message_deny[reference:27]
Пример обработчика (Python)
from flask import Flask, request, jsonify

app = Flask(__name__)
VK_CONFIRM = "your_confirmation_string"
VK_SECRET = "your_secret_key"

@app.route('/api/vk/callback', methods=['POST'])
def vk_callback():
    data = request.json
    
    # Проверка секретного ключа
    if data.get('secret') != VK_SECRET:
        return jsonify({'error': 'invalid secret'}), 403
    
    # Подтверждение сервера
    if data.get('type') == 'confirmation':
        return VK_CONFIRM
    
    # Обработка нового сообщения
    if data.get('type') == 'message_new':
        obj = data['object']['message']
        user_id = obj['from_id']
        text = obj['text']
        # ... логика бота ...
        return 'ok'
    
    return 'ok'
Можно подключить до 10 серверов для Callback API, задать каждому отдельный набор событий и версию API[reference:28].
7. LONGPOLL API

LongPoll API — альтернативный механизм получения событий, при котором клиент держит долгосрочное соединение с сервером VK и получает обновления в реальном времени. В отличие от Callback API, здесь события приходят на клиент, а не на сервер[reference:29].

ТипОписаниеПрименение
User LongPollСобытия от имени пользователяЛичные сообщения, друзья, уведомления
Bots LongPollСобытия сообщества (боты)Сообщения в беседах, команды
Настройка Bots LongPoll
1. Раздел
Управление → Работа с API → Long Poll API[reference:30]
2. Включить
Активировать Long Poll API
3. Версия
5.199
4. Типы событий
Входящие сообщения, действия в беседах и т.д.
Пример Bots LongPoll (Python)
import vk_api
from vk_api.bot_longpoll import VkBotLongPoll, VkBotEventType

vk_session = vk_api.VkApi(token='your_group_token')
longpoll = VkBotLongPoll(vk_session, 'your_group_id')

for event in longpoll.listen():
    if event.type == VkBotEventType.MESSAGE_NEW:
        msg = event.object.message
        user_id = msg['from_id']
        text = msg['text']
        
        # Отправка ответа
        vk_session.method('messages.send', {
            'user_id': user_id,
            'message': f'Вы написали: {text}',
            'random_id': 0
        })
Bots LongPoll API поддерживает последнюю версию VK API и позволяет создавать ботов с обработкой команд и кнопок[reference:31].

9. МЕТОД EXECUTE

Метод execute позволяет выполнять VKScript-код на серверах VK, что даёт возможность пакетной обработки до 25 методов в одном запросе[reference:39].

Пример использования
const result = await api.execute({
  code: `
    var users = API.users.get({ user_ids: [1, 2, 3] });
    var groups = API.groups.getById({ group_ids: ['vk'] });
    return { users: users, groups: groups };
  `
});
Преимущества
Экономия лимитов
До 25 методов за 1 запрос[reference:40]
Снижение latency
Меньше round-trip'ов до сервера
Атомарность
Все методы выполняются в одном контексте
Метод execute не имеет категории, поэтому в схеме он доступен как rvk::methods::execute[reference:41].

11. ПРИМЕРЫ КОДА
Получение информации о пользователях
import requests

ACCESS_TOKEN = "your_token"
API_VERSION = "5.199"

def get_users(user_ids):
    url = "https://api.vk.com/method/users.get"
    params = {
        "user_ids": ",".join(map(str, user_ids)),
        "fields": "city,photo_100,counters",
        "v": API_VERSION,
        "access_token": ACCESS_TOKEN
    }
    resp = requests.get(url, params=params).json()
    
    if "error" in resp:
        raise Exception(f"VK API error: {resp['error']['error_msg']}")
    
    return resp["response"]

# Использование
users = get_users([1, 210700286])
for u in users:
    print(f"{u['first_name']} {u['last_name']}")
Отправка сообщения
def send_message(user_id, text):
    url = "https://api.vk.com/method/messages.send"
    params = {
        "user_id": user_id,
        "message": text,
        "random_id": 0,
        "v": API_VERSION,
        "access_token": ACCESS_TOKEN
    }
    resp = requests.get(url, params=params).json()
    
    if "error" in resp:
        if resp["error"]["error_code"] == 14:
            # Captcha needed — обработать
            redirect_uri = resp["error"]["redirect_uri"]
            print(f"Captcha required: {redirect_uri}")
            return None
        raise Exception(resp["error"]["error_msg"])
    
    return resp["response"]
Обработка ошибок с retry
import time

def vk_request(method, params, max_retries=3):
    for attempt in range(max_retries):
        url = f"https://api.vk.com/method/{method}"
        params["v"] = API_VERSION
        params["access_token"] = ACCESS_TOKEN
        
        resp = requests.get(url, params=params).json()
        
        if "error" not in resp:
            return resp["response"]
        
        error = resp["error"]
        code = error["error_code"]
        
        # Слишком много запросов — ждём
        if code == 6:
            time.sleep(1)
            continue
        
        # Ошибка сервера — ждём и повторяем
        if code in (1, 10):
            time.sleep(2)
            continue
        
        # Неизлечимая ошибка
        raise Exception(f"VK API error {code}: {error['error_msg']}")
    
    raise Exception("Max retries exceeded")
Callback API + LongPoll: полный бот
import vk_api
from vk_api.bot_longpoll import VkBotLongPoll, VkBotEventType
from vk_api.utils import get_random_id

vk_session = vk_api.VkApi(token='group_token')
vk = vk_session.get_api()
longpoll = VkBotLongPoll(vk_session, 'group_id')

def handle_message(event):
    msg = event.object.message
    user_id = msg['from_id']
    text = msg['text'].lower()
    
    # Эхо-бот
    vk.messages.send(
        user_id=user_id,
        message=f"Эхо: {text}",
        random_id=get_random_id()
    )

def main():
    print("Bot started...")
    for event in longpoll.listen():
        if event.type == VkBotEventType.MESSAGE_NEW:
            handle_message(event)
        elif event.type == VkBotEventType.MESSAGE_TYPING_STATE:
            print(f"Typing from {event.object['from_id']}...")

if __name__ == '__main__':
    main()
