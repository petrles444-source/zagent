Ада — телеграм-бот

Помощница для личных чатов и бесед. Откликается на «Ада» в любом написании, в беседе вмешивается в каждое десятое сообщение и помнит ход разговора.

z

zradio

Радиоклиент для Windows: окно и консоль, пинг доступности станций, воспроизведение через WMP ActiveX. Окно прячется и возвращается командой — музыка не прерывается.

  • 37 станций, личная подборка первой
  • DoEvents обязателен: без него state=9 навсегда
  • лаунчер .exe собирается из C# без зависимостей

S

Генератор .swf

Собирает настоящие несжатые .swf прямо из Python: заголовок, сцена, DefineShape, PlaceObject2, кадры. Из них получаются анимации, которые играет Ruffle в браузере.

  • файлы по 800–4000 байт вместо мегабайт
  • выравнивание после RECT, порядок байт, 13-битные заголовки
  • три готовых демо в комплекте

P

Прокси помощника

Серверный ключ нельзя отдавать странице. Прокси держит его у себя, наружу отдаёт один маршрут с проверкой источника, лимитом запросов и обрезкой истории.

  • агент на 127.0.0.1 наружу не выпускается
  • лимит: без него один человек выжигает квоту за ночь
  • тексты ошибок наружу не уходят

Агент zagent

Очередь задач, файлы, воркспейсы, встроенные модели, телеграм-боты, пинги и диагностика. Ключи лежат только на машине, в коде их нет.

  • failover по моделям с картой исходящих адресов
  • журнал ошибок и проверка окружения
  • всё на стандартной библиотеке

03

Как повторить у себя

  1. Поставь Python 3.9+. Больше ничего ставить не нужно: во всех инструментах только стандартная библиотека.
  2. Скопируй файл и запусти. Например python zradio.py — откроется окно со списком станций.
  3. Ключи положи не в код, а в настройки. Файл config.json рядом со скриптом; он в списке игнорируемых.
  4. Для бота отключи приватность. @BotFather → /setprivacy → Disable, иначе в беседе он увидит только реплики с упоминанием.
  5. Для сайта положи движок рядом. Папка ruffle/ рядом с index.html — сайт работает без интернета.
