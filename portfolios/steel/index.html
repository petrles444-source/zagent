Сталь и стекло.
Пять работ,
вырезанных из листа.

Эта страница — инженерный скет, а не витрина. Тот же приём, что и в стали: сначала заготовка, потом детали. Здесь заготовка — белый лист со штриховкой и точечной сеткой, а детали — то, что осталось после всех решений: что осталось на месте, что пришлось убрать и почему так вышло дешевле, чем обещали.

скет · 1/2 · листа А4 два

Сталь

Материал, который не спорит с чертежом. Холодный серый без единого цветного оттенка, строгая сетка, острые прямые углы. Панели не украшают — они держат.

Стекло

Полупрозрачность как проверка честности: сквозь панель видно сетку, значит панель действительно стеклянная, а не просто светло-серая. У каждой панели есть собственный фон, размытие только добавляет глубину.

Пять работ

01

Neural Archive

сайт на uCoz · zagent.do.am

Архив флеш-работ с живым воспроизведением прямо в браузере. Движок Ruffle лежит рядом со страницей, в папке ruffle/, вместе со шрифтами и демо-файлами, и страница не зависит от интернета. Каталог с фильтрами, пауза, полный экран, загрузка своей .swf перетаскиванием в окно — файл читается в браузере и никуда не уходит.

Выкладка сделана обычным FTP: tools/upload_site.py заливает папку сборки на s726.ucoz.net через ftplib. Двоичный режим TYPE I обязателен — без него портятся .wasm.

  • Версия движка в проекте: Ruffle 0.7.0-nightly, WebGPU с откатом на Canvas
  • В каталоге три работы: «Пульс» — 48 кадров, «Орбита» — 108, «Столбики» — 240
  • Файлы .swf весят 832, 1876 и 4230 байта: собраны собственным генератором, не скачаны
  • На странице нет ни одного внешнего адреса загрузки
02

Ада и Линда

телеграм-боты на PythonAnywhere

Два бота, написанных только на стандартной библиотеке: urllib, json, re — больше на бесплатном тарифе всё равно не поставить. Обновления берутся длинным опросом getUpdates.

Персонажи записаны отдельными файлами, а не в коде бота: правка характера не должна была ломать разбор сообщений. На /АДА бот отвечает коротко и по делу, на /ЛОХ — тем же голосом, но объясняет, зачем.

  • Токены ботов лежат в конфиге на сервере, в коде их нет
  • Репозиторий бота закрыт от публичного доступа по причине утечки токена
  • История диалогов не сохраняется на диске: только в памяти процесса
03

Клиент Xray для Windows

Python · pystray · значок в трее

Приложение ставит соединение через Xray, держит значок в трее и даёт переключать серверы без окна. Конфиг не хранится рядом с программой в открытом виде: он собирается в памяти и пишется только на время работы ядра.

Подключение выбирается по задержке, а не по первому ответившей серверу: список нод проверяется реальным запросом, потому что «открытый» адрес ещё ничего не значит — он может принимать соединение и не выпускать в интернет.

  • Проверка списка идёт пачками по 40 адресов, не по одному
  • Ключи читаются из переменных окружения, не из файла в репозитории
  • Работает без прав администратора
04

Генерация изображений на Colab

бесплатный GPU · Stable Diffusion

Блокноты, которые сами ставят веса и поднимают сервер восстановления. Модели тянут с huggingface.co, и здесь затык оказался неочевидным: сеть рвётся на длинных файлах, поэтому пришлось сверять размер с эталоном из API, а не доверять сообщению об успехе.

Три модели держатся в проекте: Realistic Vision 5.1 и DreamShaper 8 для реалистичных кадров, SDXL Base для крупных форматов. Общий вес — больше десяти гигабайт, поэтому всё качается при первом запуске, а не хранится в репозитории.

  • Realistic Vision V5.1 fp16 — 1,99 ГБ; DreamShaper 8 — 1,99 ГБ; SDXL Base — 6,46 ГБ
  • Сессия Colab не выживает перезапуск: веса пропадают вместе с рантаймом
  • Проверка размера файла против эталонного значения из HF API — обязательный шаг
05

Инструменты

сборочные скрипты проекта

Набор скриптов, которые собирают проект целиком: сайт, пакеты для раздачи, иконки, проверка ссылок и секретов. Каждый собирает что-то одно и отказывается работать молча — если файл не найден, скрипт говорит об этом словами и останавливается.

Отдельная проверка ищет ключи и токены в собираемых архивах: пакет с ключом переписывается и не выходит в раздачу. Это страховка от того, что git add . однажды отправит их в публичный репозиторий.

  • Сборка сайта проверяет, что каждая ссылка страницы ведёт в существующий файл
  • Пароль FTP читается только из переменной окружения и не попадает в код
  • Сборка пакетов останавливается на файле с секретом и называет его

Что оказалось неочевидным

Хостинг не умеет папки — умеет, если попросить
Вывод «по FTP нельзя создать папку» был неверным: явная команда MKD проходит, а отказ касался вложенного пути целиком. Поэтому в загрузчике шаг создания папки отдельный и проверяемый: сначала папка, потом файлы внутрь.
Двадцать дней кэша
uCoz отдаёт документы с Cache-Control: max-age=1728000. Из-за этого загруженный заново скрипт браузер не запрашивает неделями, и страница выглядит как «ничего не изменилось», хотя изменилось всё. Поэтому в ссылки на локальные файлы дописывается метка содержимого ?v=….
Метка содержимого вместо ручного версионирования
Номер версии надо где-то хранить, и в какой-то момент про него забывают. Метка считается от самих файлов: меняется ровно тогда, когда меняется файл. Правки в исходниках не остаются — метка ставится на копию во временной папке, иначе метки начали бы накапливаться одна на другой.
Стекло без подложки нечитаемо
backdrop-filter — украшение, а не основа. В браузерах без его поддержки панель становится пустой, если её фон — только полупрозрачность. Поэтому у каждой стеклянной панели есть собственный непрозрачный фон, а размытие лишь добавляет глубину.
Ошибка молчит там, где проверки нет
Загрузчик сайта брал только файлы верхнего уровня, а картинки лежали в подпапке. Он рапортовал об успехе, страница отдавала 404, и это выглядело как «слайдер сломался». Теперь сборка сверяет каждую ссылку страницы с содержимым сборки.
Токен в переписке — это утечка
Токен бота, однажды вставленный в чат, считается скомпрометированным: его надо перевыпустить, а не «стереть из сообщения». Поэтому в проекте токены лежат только в конфиге на сервере и в .gitignore, а в коде их нет вовсе.

Как повторить у себя

  1. Поставить Python 3.11+ и создать окружение: python -m venv .venv. Больше ничего не нужно — зависимостей у проекта нет.
  2. Положить ключи провайдеров в config/secrets.local.json. Этот файл в .gitignore и в репозиторий не попадает.
  3. Собрать config.json бота: скрипт читает секреты, собирает конфиг в памяти и отправляет на сервер — промежуточного файла с ключами на диске не возникает.
  4. Залить код и настроить веб-приложение: 
    .venv\Scripts\python.exe hosting\pythonanywhere\deploy.py --all
  5. Задать пароль FTP в переменной окружения и выложить сайт: 
    set ZAGENT_FTP_PASS=...
.venv\Scripts\python.exe tools\upload_site.py
