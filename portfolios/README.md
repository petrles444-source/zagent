# Портфолио

Три страницы с разными дизайнами, каждая на своём адресе. Общего кода
между ними нет намеренно: если завтра понадобится поменять вёрстку в
одной, другие не должны поехать вместе с ней.

| Адрес | Папка | Подача |
|-------|-------|--------|
| `https://zagent.do.am/aurum/` | `aurum/` | тёплое золото на светлой базе: антиква, тонкие линии, воздух |
| `https://zagent.do.am/lumen/` | `lumen/` | холодное стекло: полупрозрачные панели, гротеск без засечек |
| `https://zagent.do.am/onyx/` | `onyx/` | тёмный люкс: графит и champagne, линейки и пустое поле |
| `https://zagent.do.am/neon/` | `neon/` | тёмный кибер: свечение, помехи, срезанные углы |
| `https://zagent.do.am/paper/` | `paper/` | светлая печать: бумага, засечки, две колонки |
| `https://zagent.do.am/term/` | `term/` | терминал: моноширинный, живой промпт внизу |

Различия не только в цвете: у aurum антиква и трекинг, у lumen стекло
и размытие, у onyx нумерация и модульная сетка, у neon сетка карточек
и глитч, у paper журнальные колонки и буквица, у term окно терминала
и команды. Содержание одно и то же — описание пяти работ, нюансы,
стоявшие дороже всего, и пошаговая сборка у себя.

Витрина на все шесть адресов: `https://zagent.do.am/catalog.html`
(исходник — `site/catalog.html`, он же попадает в сборку сайта).

## Что внутри

```
aurum/index.html  aurum/style.css  aurum/favicon.ico
lumen/index.html  lumen/style.css  lumen/favicon.ico
onyx/index.html   onyx/style.css   onyx/favicon.ico
neon/index.html   neon/style.css   neon/fonts/     шрифты лежат рядом
paper/index.html  paper/style.css               шрифты системные
term/index.html   term/style.css   term/app.js    поведение консоли
```

Три новые страницы (`aurum`, `lumen`, `onyx`) используют только
системные шрифты — подключать гарнитуры ради них незачем, ритм держат
трекинг и ширина колонки. Иконки для них рисует
`tools/make_favicons.py`: круглый диск в цветах своей страницы и буква
названия, `.ico` сразу из шести размеров.

Внешних адресов, с которых что-то грузится, нет ни на одной странице:
ссылки на сайты за ключами ведут туда, куда и должны, но ничего не
загружают. Проверено и в коде сборки, и в браузере по списку запросов.

## Выкладка

```bat
set ZAGENT_FTP_HOST=s726.ucoz.net
set ZAGENT_FTP_USER=8zagent
set ZAGENT_FTP_PASS=...
.venv\Scripts\python.exe tools\upload_portfolios.py
.venv\Scripts\python.exe tools\upload_portfolios.py --only term
.venv\Scripts\python.exe tools\upload_portfolios.py --dry-run
```

Пароль читается только из переменной окружения. В коде его нет.

### Про создание папок

Раньше вывод был «по FTP нельзя создать папку». Вывод неверный: явная
команда `MKD` проходит, а отказ касался вложенного пути целиком. Поэтому
в загрузчике шаг создания папки отдельный и проверяемый: сначала папка,
потом файлы внутрь.

### Метка сборки

uCoz отдаёт документы с `Cache-Control: max-age=1728000` — двадцать
дней. Из-за этого загруженный заново `app.js` браузер до двадцати дней
не перезапрашивает, и страница продолжает работать на старой версии.
Поэтому перед отправкой в ссылки на локальные `css` и `js` дописывается
`?v=<метка>`, а в подвале каждой страницы есть ссылка «сборка · обновить».

Метка считается от содержимого самих файлов, поэтому меняется ровно
тогда, когда меняется файл. Правки в исходниках не остаются: метка
ставится на копии во временной папке, иначе при следующей загрузке
метки начали бы накапливаться одна на другой.

## Терминал: команды

Печатать можно прямо на странице, поле ввода не нужно.

| Клавиши | Действие |
|---------|----------|
| `help` | список команд |
| `works`, `keys`, `howto`, `notes`, `status` | открыть раздел |
| `clear` или `Ctrl+L` | скрыть все разделы |
| `Esc` | наверх страницы |
| `↑` `↓` | история команд |

Клик по строке в таблице команд тоже её выполняет.

## Чего на страницах нет

Кнопки «скачать zagent» — заглушка: архив ещё не собран для раздачи, и
обещать загрузку, которой нет, неправильно. Всё остальное на страницах
работает прямо сейчас.
