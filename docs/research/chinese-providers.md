# Бесплатные тарифы китайских/азиатских LLM-API для стороннего Python-клиента (httpx, OpenAI-совместимый `/chat/completions`)

**Дата сбора данных: 2026-10-05.** Все цены/лимиты сверялись с официальными страницами провайдеров через web_fetch в эту дату (в карточках указана дата «Last Updated» со страницы, если она есть).

## 0. Методология и честные оговорки

- **«подтверждено официальной страницей»** — я сам открыл и прочитал страницу провайдера (docs/pricing/help), ссылка в поле «Источники».
- **«подтверждено сторонним источником»** — цифра есть только в агрегаторах/issue/GitHub; официальную страницу подтвердить не удалось (часто из-за JS-рендеринга: Volcengine docs, Baidu Qianfan, bigmodel/billing).
- **«не подтверждено»** — слухи/старые данные, официального подтверждения нет.
- Крупный сторонний агрегатор, использованный для перекрёстной проверки (обновление 2026-10-04, скрипт сверяет официальные страницы и помечает невоспроизводимые утверждения как «不予采信» / «не принимать на веру»): [rockbenben/free-llm-intel](https://github.com/rockbenben/free-llm-intel).
- **Важное ограничение этого отчёта:** я не мог эмпирически дёрнуть API (нет ключей), поэтому пункт 5 («работает ли из стороннего клиента») доказывается официальной документацией провайдера, где прямо показан вызов по обычному API-ключу из OpenAI SDK / cURL / стороннего клиента. Там, где официальной такой документации нет — так и написано.

## 2. Карточки провайдеров (строго по 8 полям)

### 2.1 Alibaba Qwen / DashScope / Model Studio (Alibaba Cloud)

1. **Название:** Alibaba Cloud Model Studio (百炼 / Bailian), бывший DashScope; модели Qwen (通义千问) + сторонние (DeepSeek, Kimi, GLM, MiniMax).
2. **Base URL и путь:** OpenAI-совместимый протокол — **да** (есть и Anthropic-совместимый).
   - Сингапур: `https://{WorkspaceId}.ap-southeast-1.maas.aliyuncs.com/compatible-mode/v1` → `POST .../compatible-mode/v1/chat/completions`
   - США (Вирджиния): `https://dashscope-us.aliyuncs.com/compatible-mode/v1/chat/completions`
   - Гонконг: `https://{WorkspaceId}.cn-hongkong.maas.aliyuncs.com/compatible-mode/v1/chat/completions`
   - Токио: `https://{WorkspaceId}.ap-northeast-1.maas.aliyuncs.com/compatible-mode/v1/chat/completions`
   - Легаси (всё ещё работают): `https://dashscope-intl.aliyuncs.com/compatible-mode/v1` (Сингапур), `https://dashscope.aliyuncs.com/compatible-mode/v1` (Пекин).
   - **Важно:** API-ключ привязан к региону. Ключ Пекина на сингапурском эндпоинте → HTTP 401 `invalid_api_key`.
3. **Как получить бесплатный ключ:** регистрация Alibaba Cloud + активация Model Studio. Для международного (Сингапур) аккаунта нужно **заполнить данные аккаунта** (телефон/личные данные) — с 15 сентября 2026 это обязательное условие активации. Для китайского региона (Пекин): **实名认证 для бесплатной квоты НЕ требуется** — официциальный текст: «无需实名认证即可获取和使用免费额度» (верификация нужна только чтобы продолжить платно после исчерпания). Явного требования банковской карты на страницах free-quota/get-api-key (англ. и кит.) я **не нашёл** — «не найдено».
4. **Что именно бесплатно:** квота выдаётся автоматически при первой активации. **Обычно 1 000 000 токенов на каждую модель** (input+output считаются из одного общего лимита), срок — **90 дней** с момента активации/релиза модели. Снапшот-версии (`qwen3.7-max-2026-05-17`) и «последняя» (`qwen3.7-max`) — **разные модели с разными квотами**. Квоты не суммируются между моделями. Квота покрывает только real-time inference (не batch, не fine-tuning, не деплой). Модели без бесплатной квоты существуют. Есть переключатель «Free Quota Only»: при исчерпании возвращает 403 `AllocationQuota.FreeTierOnly`. Для неприверифицированных китайских аккаунтов этот режим включён принудительно. Для Yi-моделей на этой же платформе квота отдельная: 1 000 000 токенов, **180 дней**.
5. **КРИТИЧНО — работает ли из стороннего клиента:** **ДА, официально подтверждено.** В документации есть целый раздел «Configure a third-party client»: base_url = `https://{WorkspaceId}.ap-southeast-1.maas.aliyuncs.com/compatible-mode/v1`, ключ обычный, примеры на OpenAI SDK, `langchain_openai`, cURL и HTTP. Никакого требования использовать их собственный клиент/консоль нет. Единственное известное ограничение — некоторые модели не поддерживают HTTP-вызов через OpenAI-совместимый интерфейс: сервер вернёт **HTTP 400 `current user api does not support http call`** (пример из документации — `qvq-max`). Это ограничение модели, а не «free tier only in our client».
6. **Доступность из России:** официальных заявлений о блокировках РФ **не найдено**. Практически: международный (Сингапур) контур доступен по email/телефону; для активации Model Studio требуется заполнить профиль аккаунта (потребуется действующий номер телефона). Иностранная карта: **не найдено** требований для получения именно бесплатной квоты; для перехода на pay-as-you-go — привязка платежа, вероятно, потребуется.
7. **Источники:**
   - Free quota: https://www.alibabacloud.com/help/en/model-studio/new-free-quota (Last Updated: Sep 22, 2026)
   - RU-регион (кит.): https://help.aliyun.com/zh/model-studio/new-free-quota
   - OpenAI-совместимость: https://www.alibabacloud.com/help/en/model-studio/compatibility-of-openai-with-dashscope (Last Updated: Sep 28, 2026)
   - API-ключи: https://www.alibabacloud.com/help/en/model-studio/get-api-key (Last Updated: Sep 28, 2026)
   - Yi-модели: https://help.aliyun.com/zh/model-studio/billing-for-yi-large
8. **Метка достоверности:** **подтверждено официальной страницей.**

### 2.2 DeepSeek (api.deepseek.com)

1. **Название:** DeepSeek (深度求索).
2. **Base URL:** `https://api.deepseek.com` (OpenAI-формат), полный путь `POST https://api.deepseek.com/chat/completions`. Есть также Anthropic-совместимый `https://api.deepseek.com/anthropic`. **OpenAI-совместим: да.**
3. **Как получить бесплатный ключ:** бесплатного ключа нет. Регистрация на `https://platform.deepseek.com/api_keys`, пополнение баланса.
4. **Что бесплатно:** **ничего.** Официальный прайс-лист содержит только платные модели: `deepseek-flash` (DeepSeek-V4.1-Flash) и `deepseek-v4-pro` (DeepSeek-V4-Pro-0813). Максимум «промо» — off-peak цены вдвое ниже пиковых (пик: 01:00–04:00 и 06:00–10:00 UTC, пн–пт). В документации упоминается «granted balance» (подарочный баланс) как источник списания, но **публичной политики выдачи бесплатных токенов нет** — «не найдено».
5. **КРИТИЧНО (сторонний клиент):** API работает из любого клиента (официальная документация прямо описывает OpenAI SDK с `extra_body={"user_id": ...}` и Anthropic SDK) — но это платный доступ, «бесплатного tier» как такового не существует. Лимит — не RPM/RPD, а **concurrency**: `deepseek-flash` — 2500 параллельных соединений, `deepseek-v4-pro` — 500. Превышение → HTTP 429.
6. **Доступность из России:** официальных данных о блокировках **не найдено**. Требуется иностранная карта для оплаты (российские карты не работают с большинством зарубежных платёжных шлюзов) — это не подтверждено страницей DeepSeek, отмечу как «не найдено».
7. **Источники:**
   - https://api-docs.deepseek.com/quick_start/pricing
   - https://api-docs.deepseek.com/quick_start/rate_limit
   - https://api-docs.deepseek.com/news/news260910 (релиз V4.1-Flash, 2026/09/10)
8. **Метка:** **подтверждено официальной страницей** (факт отсутствия бесплатного слоя).

### 2.4 Moonshot Kimi (api.moonshot.cn / platform.kimi.ai)

1. **Название:** Kimi Open Platform (月之暗面 / Moonshot AI).
2. **Base URL:** `https://api.moonshot.cn/v1` (OpenAI-совместимый, **да**); международная платформа — `https://platform.kimi.ai`. Полный путь: `POST /v1/chat/completions`.
3. **Как получить бесплатный ключ:** регистрация + **实名认证** (китайская верификация личности). Банковская карта: для бесплатного купона не нужна, но **для начала использования требуется пополнить минимум $1** (официальная страница Recharge and Rate Limiting: «you need to recharge at least $1 to start using»).
4. **Что именно бесплатно:** **бесплатных моделей нет.** Все модели платные: `kimi-k3` ($3 input / $15 output / $0.30 cached input за 1M), `kimi-k2.7-code`, `kimi-k2.6`, `kimi-k2.7-code-highspeed`. Компенсация за верификацию — **купон 15 ¥** (по данным стороннего агрегатора: https://platform.kimi.com/docs/guide/account-and-payments), причём по официальным материалам **`kimi-k3` купоном нового пользователя оплатить нельзя**. При пополнении $5 выдаётся ваучер $5 (официальная страница лимитов). Лимиты (RPM/TPM/TPD) зависят от **суммарного пополнения** и раскрываются в таблице тарифов аккаунта; бесплатного tier нет.
5. **КРИТИЧНО (сторонний клиент):** сам API — обычный OpenAI-совместимый, вызывается из любого клиента. Но «бесплатного доступа из стороннего клиента» не существует: чтобы вообще начать, нужен минимум $1 на балансе. Ограничений вида «только наш клиент» **не найдено**.
6. **Доступность из России:** официальных данных о блокировках **не найдено**. Практически требуется китайский номер и 实名认证 + пополнение (иностранная карта).

### 2.5 SiliconFlow (硅基流动)

1. **Название:** SiliconFlow (硅基流动).
2. **Base URL:** `https://api.siliconflow.cn/v1`, полный путь `POST https://api.siliconflow.cn/v1/chat/completions`. **OpenAI-совместим: да** (официальный quickstart: `from openai import OpenAI; base_url="https://api.siliconflow.cn/v1"`). Исторический `api.siliconflow.com` **отключён** (официальный changelog от 2025-03-11: мигрируйте на `.cn`).
3. **Как получить бесплатный ключ:** регистрация (SMS или email) → **обязательная 实名认证** (реальная верификация личности). **Это критично для РФ:** официально поддерживаются только документы: 身份证, 港澳通行证, 台胞证, 港澳居民居住证, 台湾居民居住证, **иностранцы — только «外国人永久居留证» (ПМЖ КНР)**. Верификация проходит через сканирование QR-кода приложением **Alipay** с распознаванием лица. У гражданина РФ без ПМЖ КНР пройти её нельзя (в доке есть форма «связаться», но она не гарантирует прохождение). Банковская карта для бесплатных моделей не нужна.
4. **Что именно бесплатно:** официальная страница Rate Limits прямо говорит: **«实名认证后使用全部的免费模型»** (после верификации доступны все бесплатные модели), «免费模型调用免费» (вызов бесплатных моделей бесплатен, в биллинге стоимость 0), **лимиты бесплатных моделей фиксированные** (не зависят от уровня трат L0–L5). Конкретный список бесплатных ID на официальной странице не перечислен (он в «модельном зале», который JS-рендерится); по данным стороннего агрегатора это: `PaddleOCR-VL-1.5`, `Hunyuan-MT-7B`, `bge-m3`, `bge-reranker-v2-m3`, `Kolors`, ASR/TTS-серии — **маленькие/векторные/картиночные модели, не флагманские LLM**. Флагманы (DeepSeek-V4, GLM, Kimi, Qwen) — платные; новым пользователям дают ~14 ¥ купоном (сторонний источник). Лимиты бенчмарков официально заданы так: LLM RPM=1000–10000, TPM=50000–5000000; embedding RPM 2000–10000; reranker RPM 2000; image IPM=2, IPD=400.
5. **КРИТИЧНО (сторонний клиент):** **ДА** — официальная документация показывает вызов по API-ключу из OpenAI SDK и по REST; ограничений «только наш клиент» нет. **НО** с 2026-05-15 действует официальное правило: «未完成实名认证的账户将无法使用平台功能» — без китайской верификации аккаунт вообще не работает.

## 3. Отдельный разбор: DeepSeek, Qwen и Grok — есть ли реально бесплатный API для сторонних клиентов в 2026?

### 3.1 DeepSeek — **бесплатного API нет**

- Официальный прайс (2026-10-05): только `deepseek-flash` и `deepseek-v4-pro`, обе платные. Off-peak = 50% от peak (peak: 01:00–04:00 и 06:00–10:00 UTC, пн–пт).
- Официальный changelog (`/news/news260910`, релиз V4.1-Flash 2026/09/10) говорит только о **снижении цен** («Lower API prices»), а не о бесплатном доступе.
- В доке есть понятие «granted balance» (подарочный баланс), но публичной политики его выдачи ноль. Popular-слух про «5 млн токенов бесплатно на 30 дней» официальной страницей **не подтверждается**.
- **Вывод: нет.** DeepSeek честно бесплатен только в веб-чате/приложении, но не через API. Единственная «экономия» — off-peak.

### 3.2 Qwen — **да, но это не «вечный free tier», а 90-дневная квота на модель**

- Alibaba Cloud Model Studio выдаёт **~1 000 000 токенов на каждую модель, 90 дней**, автоматически при активации. Это распространяется на весь каталог, включая **сторонние модели** (DeepSeek, Kimi, GLM, MiniMax), что делает аккаунт крайне удобным для оркестрации.
- Работает из обычного OpenAI-совместимого клиента по API-ключу — подтверждено официальным разделом «Configure a third-party client». То есть «только наш клиент» — нет, это не OpenCode Zen-подобная история.
- Подвох: ключи региональные (401 при несовпадении региона), квота на модель не переносится, после исчерпания (если не включён режим Free Quota Only) начинается платное списание. Для РФ практичнее Сингапурский контур + заполнение профиля.
- **Вывод: да, реально бесплатно, но это «пробная ёмкость», а не постоянный бесплатный tier.**

### 3.3 Grok (xAI) — **бесплатного API для сторонних клиентов нет**

- Официальная страница цен xAI (fetched 2026-10-05, `docs.x.ai/developers/pricing.md`) содержит **только платные** строки: `grok-4.7` ($2.00 in / $6.00 out за 1M при <200k промпта), `grok-4.6`, `grok-4.5`, `grok-4.3`, `grok-4.20-*`, `grok-build-0.1`, imagine/voice. Слово «free» встречается в одном месте и в противоположном смысле: **«It is not available on the public xAI API, and Grok Build's free tier does not include it»** — то есть бесплатный tier есть у **клиента** Grok Build (IDE/агент), а не у публичного API.
- Официальные rate limits xAI (`docs.x.ai/developers/rate-limits.md`) описывают Tier 0 = **$0 cumulative spend**, но это не бесплатные токены: лимиты даются на платный аккаунт (Tier 0: 150 RPS / 50M TPM для grok-4.7). Оплата обязательна, чтобы вообще получить доступ к моделям.
- Сторонний анализ «есть ли free tier у xAI» ([BenchLM](https://benchlm.ai/free-tier/xai), 2026) и популярные блоги, обещающие «Grok бесплатно», в своём большинстве описывают **Grok внутри X/Grok.com** (потребительский чат) или акции партнёров (Cursor и т.п.), а не API-ключ.
- **Вывод: нет.** Бесплатный Grok существует как потребительский чат/клиент, но не как API для стороннего httpx-клиента.

### 3.4 Бонус: как выглядит «настоящее» ограничение free tier — пример OpenCode Zen

Пользовательский кейс («403 free tier can only be used from within OpenCode») подтверждается косвенно:
- Официальная (зеркальная) документация Zen прямо предупреждает: **«The free OpenCode client does not make hosted inference free»**, а модели разведены по протоколам — `responses` (OpenAI adapter), `messages` (Anthropic), `chat/completions`, при этом сказано: «The built-in Zen connection handles these mappings; do not send every model to one Chat Completions endpoint» ([open-code.ai/en/docs/zen](https://open-code.ai/en/docs/zen)).
- Публичный issue: **«[BUG] OpenCode Zen free-tier /responses models fail with 403 FreeTierError when routed through the OpenCode plugin»** — [headroomlabs-ai/headroom#3656](https://github.com/headroomlabs-ai/headroom/issues/3656) (**метка: подтверждено сторонним источником/issue**).
- Вывод: Zen — пример провайдера, где значительная часть моделей доступна только через их собственный клиент/архитектуру. **У разобранных выше китайских провайдеров (Alibaba, Zhipu/Z.ai, Tencent, iFlytek, SiliconFlow, Kimi, MiniMax, Baidu, 01.AI/Yi) официальных признаков такого ограничения я не нашёл — все они документируют вызов по обычному API-ключу из OpenAI SDK/cURL.**

## 5. ТОП-5 для сценария «оркестратор параллельно спрашивает 3–5 разных моделей через один OpenAI-совместимый API»

Критерии: (а) один ключ/один base_url на много моделей, (б) строгий OpenAI-совместимый `/chat/completions`, (в) реально бесплатно и официально разрешено вызывать из стороннего клиента, (г) лимиты позволяют 3–5 параллельных запросов, (д) доступность без китайского паспорта — важный бонус для РФ.

### 🥇 1. Alibaba Cloud Model Studio (Сингапурский контур)
**Почему первый:** единственная площадка, где **один API-ключ** даёт доступ к Qwen + **чужим** моделям (DeepSeek, Kimi, GLM, MiniMax) — то есть оркестратор из 3–5 разных вендоров реализуется буквально сменой параметра `model`. Квота **на каждую модель отдельная (~1M токенов, 90 дней)**, поэтому параллельные запросы в разные модели не конкурируют за один лимит. Официально задокументирован вызов из сторонних клиентов. Для РФ доступен международный контур.
**Минусы:** ключ привязан к региону; иногда нужно «заполнить данные аккаунта»; 90 дней и потом платно (включайте Free Quota Only заранее).

### 🥈 2. OpenRouter (шлюз, не китайский)
**Почему второй:** лучший «один base_url → десятки моделей», суффикс `:free` даёт 25+ моделей, лимиты считаются **по каждой модели отдельно**, без привязки карты. Для быстрого прототипа оркестратора — минимальные усилия.
**Минусы:** 50 RPD на free-модель — для параллельной оркестрации это узко; лимиты и доступность free-моделей нестабильны (модель может исчезнуть из free). Не китайский провайдер (если нужны именно китайские модели — они там есть, но в основном платные).

### 🥉 3. Z.ai / Zhipu GLM
**Почему третий:** стабильно бесплатные flash-модели (`glm-4.7-flash`, `glm-4.5-flash`, `glm-4.6v-flash`) **без срока действия** и без оплаты, строгая OpenAI-совместимость (`https://api.z.ai/api/paas/v4/`), подтверждено официальной страницей цен. Для 3–5 параллельных запросов хватает, лимиты обычно мягкие.
**Минусы:** только модели Zhipu (нет «3–5 разных вендоров» в одном ключе); точные RPM/TPM официально не опубликованы — смотреть в консоли; в китайском контуре нужна实名认证.

### 4. Tencent Hunyuan (混元)
**Почему четвёртый:** официальный бесплатный пакет **1 000 000 токенов на 1 год** (модель `Hunyuan-a13b` + translation/vision), официальная OpenAI-совместимость (`https://api.hunyuan.cloud.tencent.com/v1/chat/completions`), и — важная деталь для оркестратора — **после исчерпания пакета не переключается на платный режим автоматически**. Лимит 5 одновременных запросов как раз покрывает «3–5 моделей параллельно».
**Минусы:** бесплатно только один основной LLM (`a13b`) + translation — «3–5 разных моделей» наберётся лишь с оговорками; нужна实名认证; срок 1 год.

### 5. SiliconFlow
**Почему пятый:** самый широкий набор **0-моделей** (векторные/rerank/OCR/перевод/картинки) плюс единый OpenAI-совместимый endpoint — отличный «второй поставщик» для оркестратора (например, embeddings и rerank бесплатно, параллельно флагманам).
**Минусы (критично для РФ):** **обязательная китайская实名认证** через Alipay с распознаванием лица; список принимаемых документов практически исключает гражданина РФ без ПМЖ КНР. Без верификации аккаунт вообще не работает (с 2026-05-15). Флагманские LLM — платные.

**Почему НЕ вошли в топ:** DeepSeek — бесплатного API нет; Grok/xAI — бесплатного API нет; MiniMax — бесплатного слоя нет; Kimi — только платно + минимальное пополнение $1; Volcengine — цифры не подтверждены официально; Baidu Qianfan — хорош (17 моделей × 1M), но требует实名认证 и подтверждение только из вторых рук.

## 6. Что осталось «не найдено» / требует перепроверки вручную

1. **Volcengine (Doubao)** — официальные страницы квот (`docs.volcengine.com/docs/82379/1263512`, `/1522733`) отдаются как JS-каркас; цифры «500 000 токенов на модель» взяты из стороннего агрегатора. **Проверить в консоли после регистрации.**
2. **Baidu Qianfan** — та же проблема JS-рендеринга: официально подтверждён только купон 20 ¥; «17 моделей × 1M / 3 мес.» — сторонний источник.
3. **Z.ai / bigmodel** — точные RPM/TPM бесплатных моделей официально не публикуются (только в личной консоли).
4. **iFlytek Spark Lite** — объём бесплатной квоты (токены/QPS/срок) на странице API-доки не указан; только «领取免费额度» на продуктовой странице.
5. **Baichuan** — программа «免费使用 M3Plus» есть, но лимиты, base_url и OpenAI-совместимость официально не опубликованы.
6. **Alibaba** — нужна ли банковская карта для получения именно бесплатной квоты (без перехода на pay-as-you-go): **не найдено**; для китайского региона实名 не требуется, для Сингапура — обязательно «заполнить данные аккаунта».
