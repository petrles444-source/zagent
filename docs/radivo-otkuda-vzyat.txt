🎵 Главное о лицензиях: что нужно знать
Прежде чем искать музыку, важно понять разницу между основными типами лицензий.

Copyright-free (свободно от авторских прав): Музыка находится в общественном достоянии (Public Domain), и у неё нет владельца. Такие треки можно использовать как угодно, но найти их сложно, и они часто старые.

Royalty-free (свободно от роялти): Это не значит «бесплатно». Обычно вы один раз платите за лицензию, а затем можете использовать трек без постоянных отчислений (роялти) правообладателю. Многие платформы предлагают такую музыку по подписке.

Creative Commons (CC): Автор даёт разрешение на использование своего произведения на определённых условиях. Обязательно проверяйте конкретную лицензию (CC BY, CC BY-SA, CC0 и т.д.) для каждого трека, так как условия могут различаться.

💎 Итоговое резюме и правила
Определите бюджет и цель: Для личного блога или некоммерческого проекта подойдут бесплатные источники вроде Mobygratis или Pixabay Music. Для коммерческого сайта, особенно с монетизацией, лучше выбрать Unminus или платную подписку (Epidemic Sound, Artlist).

Всегда проверяйте лицензию: Даже на сайтах с бесплатной музыкой условия для каждого трека могут отличаться. Ищите пометки "CC0", "Public Domain" или "Commercial Use Allowed".

Указывайте авторство, если требуется: Многие лицензии Creative Commons требуют указания автора. Это несложно сделать в футере сайта или в описании.

Остерегайтесь «бесплатной музыки» из ненадёжных источников: Скачивание треков с пиратских сайтов или из социальных сетей без явной лицензии может привести к юридическим проблемам.

Технические рекомендации: Для фона на сайте используйте инструментальные треки, избегайте вокала, который будет отвлекать. Сжимайте аудио (например, в MP3 128-192 kbps) и используйте атрибут loop в теге <audio>, чтобы музыка играла непрерывно.

/**
 * CyberRadioAgent — модуль фонового радио для встраивания в софт агента.
 *
 * Возможности:
 *  - Предустановленный список киберпанк-радиостанций
 *  - Автоматическая проверка доступности (ping) при инициализации
 *  - Переключение между станциями
 *  - Управление громкостью и паузой
 *  - События: onStationChange, onStatusChange, onError
 *
 * Использование:
 *   const radio = new CyberRadioAgent({ container: document.body });
 *   await radio.init();
 *   radio.play();
 */
class CyberRadioAgent {
  /**
   * @param {Object} options
   * @param {HTMLElement} options.container — элемент, к которому будет привязан плеер
   * @param {number} [options.volume=0.5] — начальная громкость (0..1)
   * @param {boolean} [options.autoPlay=false] — автозапуск после инициализации
   * @param {number} [options.pingTimeout=4000] — таймаут проверки доступности (мс)
   */
  constructor(options = {}) {
    this.container = options.container || document.body;
    this.volume = options.volume ?? 0.5;
    this.autoPlay = options.autoPlay ?? false;
    this.pingTimeout = options.pingTimeout ?? 4000;

    /** @type {HTMLAudioElement} */
    this.audio = null;

    /** Индекс текущей активной станции */
    this.currentIndex = 0;

    /** Статус каждой станции: 'unknown' | 'online' | 'offline' */
    this.status = [];

    /** Слушатели событий */
    this._listeners = { stationChange: [], statusChange: [], error: [] };

    /**
     * Список станций.
     * Поле `stream` — прямой URL для <audio>.
     * Поле `homepage` — страница станции (для справки).
     *
     * Станции, помеченные `needsKey: true`, требуют Listen Key от сервиса
     * и не проверяются автоматически без ключа.
     */
    this.stations = [
      {
        name: 'Nightride.fm',
        genre: 'Synthwave / Cyberpunk',
        stream: 'https://stream.nightride.fm/nightride.m4a',
        homepage: 'https://nightride.fm',
        bitrate: '320 kbps',
      },
      {
        name: 'Synthwave Radio EU',
        genre: 'Synthwave / Retrowave',
        stream: 'https://stream.synthwaveradio.eu/listen/synthwaveradio.eu/radio.mp3',
        homepage: 'https://www.synthwaveradio.eu',
        bitrate: '192 kbps',
      },
      {
        name: 'Retrowave.One',
        genre: '80s / Chillsynth / Cyberpunk',
        stream: 'http://85.234.59.191:8000/stream',
        homepage: 'https://retrowave.one',
        bitrate: '192 kbps',
        // Примечание: станция может быть недоступна из-за HTTP-потока.
      },
      {
        name: 'Radio Caprice — Cyberpunk',
        genre: 'Industrial / Dark Ambient / Cyberpunk',
        stream: 'http://79.120.12.130:8002/cyberpunk',
        homepage: 'http://radcap.ru/cyberpunk.html',
        bitrate: '320 kbps',
      },
      {
        name: 'NightGrid FM',
        genre: 'Cyberpunk / Dark Synthwave / Industrial',
        stream: 'https://radio.bitriver.tv:443/nightgrid',
        homepage: 'https://radio.bitriver.tv/nightgrid',
        bitrate: '128 kbps',
      },
      {
        name: 'DI.FM — Synthwave',
        genre: 'Synthwave',
        stream: null, // требует Listen Key
        homepage: 'https://www.di.fm/synthwave',
        bitrate: 'до 320 kbps',
        needsKey: true,
      },
      {
        name: 'PsyCoPig Radio 100',
        genre: 'Rock / Cyberpunk / Synthwave',
        stream: 'https://e20.yesstreaming.net:7104/stream',
        homepage: 'https://psycopigradio100.com',
        bitrate: '320 kbps',
      },
      {
        name: '24/7 Cyberpunk Hacker Radio',
        genre: 'Deep Ambient / Cyberpunk',
        stream: 'https://teleon.tv/stream/cyberpunk-hacker-radio',
        homepage: 'https://teleon.tv',
        bitrate: '—',
        // Примечание: поток может быть HLS/iframe — <audio> его не проиграет.
      },
    ];

    this.status = this.stations.map(() => 'unknown');
  }

  // ---------- Публичное API ----------

  /**
   * Инициализация: создание <audio>, проверка доступности станций.
   * @returns {Promise<void>}
   */
  async init() {
    this._createAudioElement();
    await this._pingAllStations();
    if (this.autoPlay) {
      this.play();
    }
  }

  /** Начать воспроизведение текущей станции. */
  play() {
    const station = this._playableStations()[this.currentIndex];
    if (!station) {
      this._emit('error', { message: 'Нет доступных станций для воспроизведения.' });
      return;
    }
    this.audio.src = station.stream;
    this.audio.volume = this.volume;
    this.audio.play().catch((err) => {
      this._emit('error', { message: `Не удалось воспроизвести: ${err.message}` });
    });
  }

  /** Пауза. */
  pause() {
    this.audio.pause();
  }

  /** Переключиться на следующую доступную станцию. */
  next() {
    const playable = this._playableStations();
    if (playable.length === 0) return;
    this.currentIndex = (this.currentIndex + 1) % playable.length;
    this.play();
    this._emit('stationChange', playable[this.currentIndex]);
  }

  /** Переключиться на предыдущую доступную станцию. */
  prev() {
    const playable = this._playableStations();
    if (playable.length === 0) return;
    this.currentIndex = (this.currentIndex - 1 + playable.length) % playable.length;
    this.play();
    this._emit('stationChange', playable[this.currentIndex]);
  }

  /** Установить громкость (0..1). */
  setVolume(value) {
    this.volume = Math.max(0, Math.min(1, value));
    if (this.audio) this.audio.volume = this.volume;
  }

  /** Получить текущую станцию. */
  getCurrentStation() {
    return this._playableStations()[this.currentIndex] || null;
  }

  /** Получить список всех станций с их статусами. */
  getStations() {
    return this.stations.map((s, i) => ({ ...s, status: this.status[i] }));
  }

  /** Получить только доступные станции. */
  getOnlineStations() {
    return this.getStations().filter((s) => s.status === 'online');
  }

  /** Подписка на событие. */
  on(event, handler) {
    if (this._listeners[event]) this._listeners[event].push(handler);
    return this;
  }

  /** Отписка. */
  off(event, handler) {
    if (this._listeners[event]) {
      this._listeners[event] = this._listeners[event].filter((h) => h !== handler);
    }
    return this;
  }

  /** Уничтожить плеер и освободить ресурсы. */
  destroy() {
    if (this.audio) {
      this.audio.pause();
      this.audio.src = '';
      this.audio.remove();
    }
    this._listeners = { stationChange: [], statusChange: [], error: [] };
  }

  // ---------- Внутренняя логика ----------

  _createAudioElement() {
    this.audio = document.createElement('audio');
    this.audio.preload = 'none';
    this.audio.crossOrigin = 'anonymous';
    this.audio.style.display = 'none';
    this.container.appendChild(this.audio);

    this.audio.addEventListener('error', () => {
      const station = this.getCurrentStation();
      this._emit('error', {
        message: `Ошибка потока: ${station?.name || 'неизвестно'}`,
        station,
      });
      // Автоматически переключаемся на следующую доступную
      const playable = this._playableStations();
      if (playable.length > 1) {
        this.next();
      }
    });
  }

  _playableStations() {
    // Для воспроизведения доступны только станции со статусом 'online'
    // и наличием stream-URL.
    return this.stations.filter(
      (s, i) => this.status[i] === 'online' && s.stream
    );
  }

  /**
   * Проверка доступности всех станций.
   * Используем fetch с AbortController и режимом 'no-cors',
   * чтобы проверить, отвечает ли сервер вообще.
   * Для <audio> это не даёт гарантии воспроизведения,
   * но отсеивает мёртвые хосты.
   */
  async _pingAllStations() {
    const tasks = this.stations.map((station, i) => {
      if (!station.stream || station.needsKey) {
        this.status[i] = 'unknown';
        return Promise.resolve();
      }
      return this._pingStation(station.stream)
        .then((ok) => {
          this.status[i] = ok ? 'online' : 'offline';
          this._emit('statusChange', {
            station,
            index: i,
            status: this.status[i],
          });
        })
        .catch(() => {
          this.status[i] = 'offline';
          this._emit('statusChange', {
            station,
            index: i,
            status: 'offline',
          });
        });
    });

    await Promise.all(tasks);
  }

  /**
   * Одиночный ping: пробуем HEAD-запрос с таймаутом.
   * Если HEAD не поддерживается — пробуем GET с отменой.
   * @param {string} url
   * @returns {Promise<boolean>}
   */
  async _pingStation(url) {
    const controller = new AbortController();
    const timer = setTimeout(() => controller.abort(), this.pingTimeout);

    try {
      // Сначала HEAD (лёгкий запрос)
      const headResp = await fetch(url, {
        method: 'HEAD',
        mode: 'no-cors',
        signal: controller.signal,
        cache: 'no-store',
      });
      clearTimeout(timer);
      // В режиме 'no-cors' status всегда 0, но сам факт ответа уже хорош.
      return true;
    } catch (headErr) {
      clearTimeout(timer);
      // Если HEAD не сработал — пробуем GET с abort сразу после заголовков
      const controller2 = new AbortController();
      const timer2 = setTimeout(() => controller2.abort(), this.pingTimeout);
      try {
        const getResp = await fetch(url, {
          method: 'GET',
          mode: 'no-cors',
          signal: controller2.signal,
          cache: 'no-store',
        });
        clearTimeout(timer2);
        // Отменяем тело, чтобы не тратить трафик
        if (getResp.body) {
          try { getResp.body.cancel(); } catch (_) {}
        }
        return true;
      } catch (getErr) {
        clearTimeout(timer2);
        return false;
      }
    }
  }

  _emit(event, payload) {
    (this._listeners[event] || []).forEach((fn) => {
      try { fn(payload); } catch (e) { console.error(e); }
    });
  }
}

Как это работает
1. Список станций
В массив this.stations включены все восемь радиостанций из вашего списка. Для каждой указан прямой потоковый URL (stream), жанр, домашняя страница и битрейт. Станция DI.FM — Synthwave помечена needsKey: true, так как для её потока требуется Listen Key, который можно получить в настройках аккаунта DI.FM.

2. Проверка пинга (_pingAllStations)
При инициализации скрипт параллельно проверяет каждую станцию:

HEAD-запрос в режиме no-cors с таймаутом (по умолчанию 4 секунды).

Если HEAD не сработал — GET-запрос с немедленной отменой тела после получения заголовков.

Результат записывается в массив this.status: 'online', 'offline' или 'unknown'.

Станции без stream или с needsKey не проверяются и остаются в статусе 'unknown'. Это сделано осознанно: попытка проверить поток DI.FM без ключа вернёт ошибку, хотя сама станция работает.

3. Воспроизведение
Для воспроизведения используются только станции со статусом 'online' и наличием stream. Метод _playableStations() возвращает отфильтрованный список, а play() устанавливает audio.src и запускает воспроизведение.

Если поток обрывается (событие error на <audio>), скрипт автоматически переключается на следующую доступную станцию — это встроенный механизм отказоустойчивости.

4. Событийная модель
Скрипт генерирует три типа событий:

Событие	Когда возникает	Payload
statusChange	После проверки пинга каждой станции	{ station, index, status }
stationChange	При переключении на другую станцию	station
error	При ошибке воспроизведения или отсутствии станций	{ message, station? }
Это позволяет встраивающему агенту реагировать на состояние радио: обновлять UI, логировать или принимать решения.

const TIMEOUT_MS = 4000;

async function pingStation(url) {
  const controller = new AbortController();
  const timer = setTimeout(() => controller.abort(), TIMEOUT_MS);
  try {
    // HEAD-запрос в no-cors — минимальная нагрузка
    await fetch(url, {
      method: 'HEAD',
      mode: 'no-cors',
      signal: controller.signal,
      cache: 'no-store',
    });
    clearTimeout(timer);
    return 'online';
  } catch {
    clearTimeout(timer);
    // Пробуем GET с немедленной отменой тела
    const controller2 = new AbortController();
    const timer2 = setTimeout(() => controller2.abort(), TIMEOUT_MS);
    try {
      const resp = await fetch(url, {
        method: 'GET',
        mode: 'no-cors',
        signal: controller2.signal,
        cache: 'no-store',
      });
      clearTimeout(timer2);
      if (resp.body) { try { resp.body.cancel(); } catch (_) {} }
      return 'online';
    } catch {
      clearTimeout(timer2);
      return 'offline';
    }
  }
}

async function pingAll() {
  const results = await Promise.all(
    STATIONS.map(async (s) => ({
      name: s.name,
      url: s.url,
      status: await pingStation(s.url),
    }))
  );
  console.table(results);
  return results;
}

Как использовать скрипт
Скопируйте код в консоль браузера или в модуль агента.

Вызовите pingAll() — скрипт параллельно проверит все 25 станций с таймаутом 4 секунды.

Результат выводится в консоль в виде таблицы: online (сервер отвечает) или offline (таймаут / ошибка сети).

Важно. Режим no-cors не даёт точного HTTP-статуса, но сам факт ответа сервера уже означает, что хост жив. Некоторые станции могут отдавать поток только по GET, поэтому скрипт делает fallback с HEAD на GET.

// ─── Инициализация ───
function init() {
  audio = new Audio();

// ─── Лог ───
function log(msg) {
  const time = new Date().toLocaleTimeString();
  logEl.innerHTML += `[${time}] ${msg}<br>`;
  logEl.scrollTop = logEl.scrollHeight;
}

// ─── Отрисовка списка ───

    div.onclick = () => playStation(i);
    list.appendChild(div);
  });
}

function bindControls() {
  document.getElementById('btnPlay').onclick = () => {
    if (currentIndex >= 0) {
      audio.play().catch(e => log('Ошибка воспроизведения: ' + e.message));

      const firstOnline = stationStatus.findIndex(s => s === 'online');
      playStation(firstOnline >= 0 ? firstOnline : 0);
    }

  document.getElementById('btnPause').onclick = () => audio.pause();

  document.getElementById('btnNext').onclick = () => nextStation();

  document.getElementById('btnPing').onclick = () => pingAll();

    audio.volume = v;
    document.getElementById('volLabel').textContent = Math.round(v * 100) + '%';
  };
}

  audio.play().catch(e => log(`Не удалось: ${s.name} — ${e.message}`));
  document.getElementById('npName').textContent = s.name;
  document.getElementById('npGenre').textContent = `${s.genre} · ${s.bitrate}`;
  renderStations();
  log(`▶ ${s.name}`);
}

function nextStation() {
  if (STATIONS.length === 0) return;
  let next = (currentIndex + 1) % STATIONS.length;
  playStation(next);
}

// ─── Пинг всех станций ───
async function pingStation(url) {
  const controller = new AbortController();
  const timer = setTimeout(() => controller.abort(), 5000);
  try {
    await fetch(url, {
      method: 'HEAD',
      mode: 'no-cors',
      signal: controller.signal,
      cache: 'no-store'
    });
    clearTimeout(timer);
    return 'online';
  } catch {
    clearTimeout(timer);
    // Fallback: GET с отменой тела
    const c2 = new AbortController();
    const t2 = setTimeout(() => c2.abort(), 5000);
    try {
      const resp = await fetch(url, {
        method: 'GET',
        mode: 'no-cors',
        signal: c2.signal,
        cache: 'no-store'
      });
      clearTimeout(t2);
      if (resp.body) { try { resp.body.cancel(); } catch (_) {} }
      return 'online';
    } catch {
      clearTimeout(t2);
      return 'offline';
    }
  }
}

async function pingAll() {
  log('Проверка станций...');
  const results = await Promise.all(
    STATIONS.map(async (s, i) => {
      const status = await pingStation(s.url);
      stationStatus[i] = status;
      return { name: s.name, status };
    })
  );
  renderStations();
  const online = results.filter(r => r.status === 'online').length;
  log(`Проверено: ${results.length}, онлайн: ${online}`);
  results.forEach(r => {
    log(`  ${r.status === 'online' ? '🟢' : '🔴'} ${r.name}`);
  });
}

// ─── Запуск ───
init();
</script>

</html>

## ⚙️ Как это работает

1. **Проверка доступности (`pingAll`)** — параллельно отправляет HEAD-запрос к каждому потоку с таймаутом 5 секунд. Если HEAD не сработал, пробует GET с немедленной отменой тела. Статус отображается цветным индикатором (🟢/🔴/🟠).

2. **Воспроизведение** — используется стандартный `Audio()` с `preload='none'`. При ошибке потока автоматически переключается на следующую станцию.

3. **Управление** — кнопки «Играть», «Пауза», «Следующая», «Проверить все», слайдер громкости.

4. **Логирование** — все действия и ошибки выводятся в консольную панель внизу.

## ⚠️ Важные замечания

- **HTTP-потоки** (Retrowave.One, Radio Caprice, PsyCoPig, Cyberpunk Hacker, GENERATION SOUL DISCO FUNK) не будут работать на HTTPS-страницах из-за блокировки смешанного контента. Для продакшена их нужно либо исключить, либо проксировать через HTTPS.
- **CORS**: атрибут `crossOrigin='anonymous'` установлен, но некоторые станции могут не отдавать CORS-заголовки. Если поток не играет — уберите этот атрибут.
- **DI.FM Synthwave** в список не включён, так как требует Listen Key из настроек аккаунта.
