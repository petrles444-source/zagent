🏗️ Архитектура и основные модули
Документация OpenCV организована вокруг нескольких ключевых модулей, каждый из которых отвечает за определенный набор функций:

core: Базовые строительные блоки библиотеки. Сюда входят структуры данных (например, Mat для изображений), математические операции и управление памятью.

imgproc: Модуль обработки изображений. Включает в себя функции для фильтрации, геометрических преобразований, цветовых пространств, пороговой обработки, поиска контуров и многого другого.

highgui, imgcodecs, videoio: Утилиты для ввода-вывода. Отвечают за отображение изображений, чтение/запись файлов и захват видео.

calib3d: Калибровка камеры и 3D-реконструкция.

objdetect: Обнаружение объектов (например, лиц или людей).

feature2d: Фреймворк для работы с признаками: детекторы, дескрипторы и сопоставление.

dnn: Модуль глубокого обучения для вывода нейронных сетей.

gapi: Графовый API для построения алгоритмов компьютерного зрения.

🚀 Ключевые нововведения в версии 4.12.0
Версия 4.12.0 привнесла ряд значительных улучшений:

Поддержка GIF: Модуль imgcodecs теперь поддерживает декодирование и кодирование GIF-файлов по умолчанию.

Улучшенная работа с PNG и Animated PNG: Улучшена обработка статических и анимированных PNG-файлов.

Поддержка Animated WebP: Добавлена поддержка анимированных изображений в формате WebP.

Новый HAL для RISC-V: Реализован новый слой аппаратной абстракции (HAL) для платформ RISC-V с векторным расширением RVV 1.0, что должно значительно повысить производительность на этих архитектурах.

Улучшения в Core: Добавлена возможность определения пользовательского колбэка для логирования, что дает больше гибкости при интеграции OpenCV в существующие системы.

Оптимизация поиска контуров: Улучшена производительность алгоритмов поиска контуров.

Новый флаг для пороговой обработки: Добавлен флаг THRESH_DRYRUN, позволяющий получить результат адаптивной пороговой обработки без фактического применения операции к изображению.

1. Базовые операции с изображениями
Этот пример показывает, как загрузить изображение, получить доступ к его пикселям, разделить на каналы и объединить обратно.

python
import cv2 as cv
import numpy as np

# Загрузка изображения
img = cv.imread('image.jpg')

# Доступ к значению пикселя (B, G, R)
px = img[100, 100]
print(f"Значение пикселя в (100, 100): {px}")

# Доступ только к синему каналу
blue = img[100, 100, 0]
print(f"Значение синего канала: {blue}")

# Изменение значения пикселя
img[100, 100] = [255, 255, 255]

# Разделение и объединение каналов
b, g, r = cv.split(img)
img_merged = cv.merge((b, g, r))

# Получение свойств изображения
print(f"Размер изображения: {img.shape}")
print(f"Тип данных: {img.dtype}")
print(f"Количество пикселей: {img.size}")
2. Обработка видео с камеры
Пример демонстрирует захват видео с веб-камеры, отображение кадров в реальном времени и сохранение видеофайла.

python
import cv2 as cv
import numpy as np

# Создание объекта VideoCapture для захвата с камеры (индекс 0)
cap = cv.VideoCapture(0)

# Определение кодека и создание объекта VideoWriter для сохранения видео
fourcc = cv.VideoWriter_fourcc(*'XVID')
out = cv.VideoWriter('output.avi', fourcc, 20.0, (640, 480))

while cap.isOpened():
    ret, frame = cap.read()
    if not ret:
        print("Не удалось получить кадр. Выход...")
        break

    # Запись кадра в файл
    out.write(frame)

    # Отображение кадра
    cv.imshow('frame', frame)

    # Выход по нажатию клавиши 'q'
    if cv.waitKey(1) & 0xFF == ord('q'):
        break

# Освобождение ресурсов
cap.release()
out.release()
cv.destroyAllWindows()
3. Поиск контуров
Этот пример показывает, как найти контуры на бинарном изображении и нарисовать их.

python
import cv2 as cv
import numpy as np

# Загрузка изображения и преобразование в оттенки серого
img = cv.imread('shapes.jpg')
gray = cv.cvtColor(img, cv.COLOR_BGR2GRAY)

# Применение пороговой обработки для получения бинарного изображения
ret, thresh = cv.threshold(gray, 127, 255, cv.THRESH_BINARY)

# Поиск контуров
contours, hierarchy = cv.findContours(thresh, cv.RETR_TREE, cv.CHAIN_APPROX_SIMPLE)
print(f"Найдено контуров: {len(contours)}")

# Рисование всех контуров на исходном изображении
cv.drawContours(img, contours, -1, (0, 255, 0), 3)

# Отображение результата
cv.imshow('Contours', img)
cv.waitKey(0)
cv.destroyAllWindows()
4. Использование DNN для классификации
Пример демонстрирует загрузку предварительно обученной модели (например, Caffe) и выполнение классификации изображения с помощью модуля dnn.

python
import cv2 as cv
import numpy as np

# Загрузка модели и файла конфигурации
net = cv.dnn.readNetFromCaffe('deploy.prototxt', 'model.caffemodel')

# Загрузка и предобработка изображения
img = cv.imread('example.jpg')
blob = cv.dnn.blobFromImage(img, 1.0, (224, 224), (104, 117, 123))

# Установка входа и выполнение прямого прохода
net.setInput(blob)
out = net.forward()

# Получение предсказанного класса
class_id = np.argmax(out)
print(f"Предсказанный класс: {class_id}, вероятность: {out[0][class_id]:.4f}")

📊 Основные модули (Core Modules)
Эти модули входят в стандартную сборку OpenCV и покрывают большинство типовых задач.

calib3d — Калибровка камеры и 3D-реконструкция
Модуль предоставляет алгоритмы для калибровки камеры, стереозрения, 3D-реконструкции и оценки позы. В его основе лежит модель камеры-обскуры с учетом дисторсии объектива.

Ключевые классы и функции:

cv::calibrateCamera(): Калибровка камеры по набору изображений с известным шаблоном.

cv::stereoRectify(): Вычисляет преобразования для выпрямления стереопары.

cv::StereoBM, cv::StereoSGBM: Классы для вычисления карты диспаратности (глубины) с использованием блочного сопоставления.

cv::solvePnP(): Оценка позы объекта (положения и ориентации) по 3D-2D соответствиям.

objdetect — Обнаружение объектов
Этот модуль содержит инструменты для поиска объектов на изображениях, включая каскадные классификаторы, HOG-детектор, а также детекторы QR-кодов и ArUco-маркеров.

Ключевые классы и функции:

cv::CascadeClassifier: Класс для обнаружения объектов с использованием каскадов Хаара или LBP (Local Binary Patterns).

cv::HOGDescriptor: Реализация дескриптора на основе гистограмм направленных градиентов и детектора объектов (например, для людей).

cv::QRCodeDetector: Детектор и декодер QR-кодов.

cv::aruco::ArucoDetector: Основной класс для обнаружения ArUco-маркеров.

feature2d — 2D-признаки
Модуль предоставляет абстрактный базовый класс для детекторов и дескрипторов 2D-признаков, а также включает реализации популярных алгоритмов.

Ключевые классы:

cv::Feature2D: Абстрактный базовый класс для всех детекторов и дескрипторов.

cv::SIFT: Масштабно-инвариантная трансформация признаков.

cv::ORB: Ориентированный FAST и вращаемый BRIEF.

cv::BRISK, cv::KAZE, cv::AKAZE: Другие современные алгоритмы.

dnn — Глубокое обучение
Модуль предназначен для вывода (инференса) нейронных сетей, загруженных из популярных фреймворков, таких как TensorFlow, PyTorch, ONNX, Caffe и Darknet. Он не поддерживает обучение сетей.

Ключевые классы и функции:

cv::dnn::readNet(): Загрузка модели из файла.

cv::dnn::blobFromImage(): Создание 4-мерного «блоба» из изображения для подачи на вход сети.

cv::dnn::Net: Класс, представляющий нейронную сеть, с методами setInput() и forward().

gapi — Графовый API
G-API — это графовый фреймворк OpenCV для построения эффективных и портируемых конвейеров обработки изображений.

Ключевые концепции:

cv::GComputation: Представляет захваченный вычислительный граф.

Бэкенды: Поддерживаются CPU (OpenCV), Fluid, OCL (OpenCL) и другие.

Источники и приёмники: Абстракции для ввода и вывода данных (например, cv::gapi::wip::GCaptureSource).

ml — Машинное обучение
Модуль реализует классические алгоритмы машинного обучения для задач классификации, регрессии и кластеризации.

Ключевые классы:

cv::ml::SVM: Машина опорных векторов.

cv::ml::KNearest: Метод k-ближайших соседей.

cv::ml::LogisticRegression: Логистическая регрессия.

cv::ml::TrainData: Класс для инкапсуляции обучающих данных.

photo — Вычислительная фотография
Модуль включает алгоритмы обработки фотографий, такие как шумоподавление, HDR-изображения, восстановление (inpainting) и бесшовное клонирование.

Ключевые функции:

cv::fastNlMeansDenoising(): Эффективное шумоподавление.

cv::inpaint(): Восстановление поврежденных участков изображения.

cv::seamlessClone(): Бесшовное клонирование одного изображения на другое.

stitching — Сшивка изображений
Модуль предоставляет полный конвейер для создания панорам из нескольких изображений, включая обнаружение и сопоставление признаков, оценку параметров камеры, выпрямление, поиск швов и смешивание.

Ключевой класс:

cv::Stitcher: Высокоуровневый класс для сшивки изображений. Метод createDefault() создает стандартный конвейер.

video — Видеоанализ
Модуль содержит алгоритмы для анализа видео, включая оценку движения (оптический поток) и вычитание фона.

Ключевые классы и функции:

cv::calcOpticalFlowPyrLK(): Вычисление разреженного оптического потока методом Лукаса-Канаде.

cv::BackgroundSubtractorMOG2: Вычитание фона на основе смеси гауссовых распределений.

videoio — Ввод-вывод видео
Модуль отвечает за чтение видео с камер и файлов, а также за запись видеофайлов.

Ключевые классы:

cv::VideoCapture: Класс для захвата видео из файла, последовательности изображений или с камеры.

cv::VideoWriter: Класс для записи видеофайлов.

text — Обнаружение и распознавание текста
Модуль содержит алгоритмы для обнаружения текста в естественных сценах и его распознавания (OCR).

Ключевые классы:

cv::text::TextDetectorCNN: Детектор текста на основе CNN.

tracking — Отслеживание объектов
Модуль предоставляет API для отслеживания объектов на видео с использованием различных алгоритмов.

Модуль для работы с квадратными бинарными маркерами, широко используемыми в задачах дополненной реальности и робототехнике.

Ключевые классы:

cv::aruco::ArucoDetector: Детектор маркеров.

cv::aruco::Board: Представление набора маркеров.

bgsegm — Вычитание фона
Модуль содержит дополнительные алгоритмы вычитания фона для выделения движущихся объектов на видео.

Ключевые классы:

cv::bgsegm::BackgroundSubtractorMOG: Гауссова смесь для сегментации фона/переднего плана.

ximgproc — Расширенная обработка изображений
Модуль предоставляет набор дополнительных фильтров и алгоритмов обработки изображений.

Примеры функций:

xphoto — Дополнительная обработка фотографий

dnn_superres — Суперразрешение через DNN

🧠 Инференс нейросетей на CPU (модуль dnn)
Модуль dnn в OpenCV 4.12.0 полностью поддерживает выполнение вывода нейронных сетей на CPU и оптимизирован для этого. Это позволяет запускать современные модели без дискретной видеокарты.

Поддерживаемые фреймворки: TensorFlow, PyTorch (через ONNX), Caffe, Darknet и другие.

Как включить CPU-режим: Достаточно установить соответствующие бэкенд и цель:

cpp
net.setPreferableBackend(cv::dnn::DNN_BACKEND_OPENCV);
net.setPreferableTarget(cv::dnn::DNN_TARGET_CPU);
В Python это делается аналогично.

Оптимизация: Можно использовать бэкенд Intel OpenVINO (если он собран с OpenCV) для дополнительного ускорения на процессорах Intel: DNN_BACKEND_INFERENCE_ENGINE + DNN_TARGET_CPU.

⚡ Параллельные вычисления на CPU

cv::parallel_for_: Фреймворк для распараллеливания собственного кода. OpenCV автоматически разбивает вычисления на потоки, используя доступные ядра.

cv::setNumThreads(): Позволяет управлять количеством потоков, используемых внутренними алгоритмами OpenCV.

Бэкенды: OpenCV может использовать различные параллельные фреймворки, такие как OpenMP, Intel TBB или pthreads, в зависимости от сборки.

⚠️ «Грабли» и регрессии производительности
Даже в стабильных версиях случаются неприятные сюрпризы, о которых лучше знать заранее.

Регрессия cv::compare в 4.12.0: В официальных сборках для Windows была обнаружена ~4-кратная просадка производительности функции cv::compare по сравнению с версией 4.11. На процессоре Intel Xeon время выполнения выросло с ~4 мс до ~15 мс, а на AMD Ryzen 5 3600 — с ~5.4 мс до ~19 мс. Интересно, что при самостоятельной сборке OpenCV без IPP (Integrated Performance Primitives) производительность возвращается к уровню 4.11.

Неочевидное поведение DNN на CPU: Один из самых частых источников проблем — «тихий» откат к CPU. Если вы установили DNN_TARGET_CUDA, но у вас нет GPU, инференс молча выполнится на CPU, а не выдаст ошибку. Кроме того, на Linux и macOS при вызове setPreferableBackend(DNN_BACKEND_CPU) OpenCV может использовать бэкенд OpenVINO, если он установлен, вместо собственного процессорного бэкенда. Для предсказуемой работы на CPU программисты советуют явно указывать DNN_BACKEND_OPENCV.

🚀 Советы по оптимизации DNN на CPU от практиков
Запуск нейросетей на процессоре — это искусство компромиссов. Вот что советуют разработчики.

«Профилируйте, а не гадайте»: Один из главных советов — всегда измерять реальную производительность. Используйте net.getPerfProfile(), чтобы получить время выполнения по слоям и понять, где именно тратится время.

Проверяйте цветовое пространство: Это классическая ошибка. Параметр swapRB=True в blobFromImage() меняет каналы BGR на RGB. Однако многие модели, экспортированные из PyTorch, уже ожидают на входе RGB, так как при обучении использовались данные в этом формате. Если вы установите swapRB=True для такой модели, каналы перепутаются, и точность инференса упадет без каких-либо ошибок в консоли.

Фиксированный размер входа: OpenCV DNN не поддерживает динамические входные размеры. Если ваша модель ожидает на входе тензор переменного размера, вы получите загадочную ошибку getMemoryShapes. Решение — всегда явно изменять размер изображения до того, который использовался при обучении модели (например, 224x224 или 640x640).

Реальный прирост от оптимизации: Практики отмечают, что грамотная оптимизация (правильные бэкенды, предобработка) может снизить время обработки одного кадра с 120 мс до 35 мс — то есть более чем в 3 раза.

⚙️ Тонкости многопоточности на CPU
Управление потоками — это палка о двух концах. Неправильная настройка может не ускорить, а замедлить вашу программу.

Почему setNumThreads() может не работать: Один разработчик на Stack Overflow провел эксперимент с cv2.setNumThreads() и обнаружил, что время выполнения GaussianBlur и boxFilter практически не менялось при переходе с 1 на 8 потоков. Опытные пользователи объяснили, что многие алгоритмы OpenCV являются однопоточными, и setNumThreads() влияет лишь на те немногие функции, которые были распараллелены внутри библиотеки.

Отключение многопоточности для стабильности: Если вы используете OpenCV внутри другого фреймворка с собственным управлением потоками (например, PyTorch DataLoader), встроенная многопоточность OpenCV может создавать конфликты и приводить к зависаниям. В таких случаях программисты рекомендуют вызывать cv2.setNumThreads(0), чтобы полностью отключить параллельные регионы OpenCV. Это делает поведение CPU более предсказуемым и, по некоторым наблюдениям, снижает общую производительность менее чем на 3% в сценариях с интенсивным вводом-выводом.

Параллелизм на уровне процессов: Для истинно CPU-зависимых задач (например, извлечение признаков, инференс) использование ProcessPoolExecutor с числом воркеров, равным количеству ядер CPU (os.cpu_count()), может дать до 23 раз больше производительности, чем потоки. Ключевой момент — разбивать данные на чанки перед отправкой в воркеры, чтобы снизить накладные расходы на межпроцессное взаимодействие.

Управление жестами: Проекты вроде HandTrackingProject на Python с использованием MediaPipe и OpenCV позволяют отслеживать руки и управлять рабочим столом жестами, работая на 30 FPS на CPU.
