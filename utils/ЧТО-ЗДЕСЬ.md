# Утилиты

Каждая утилита в своей папке и запускается сама: не требует агента, не требует сети, если не сказано иное в её инструкции.

Запуск любой: `cd utils/<имя>` и команда из её `ЧТО-ЗДЕСЬ.md`.

| Утилита | Что делает |
|---|---|
| `cheker` | Проверка страниц на хостинге |
| `sborka-saytov` | Сборка сайтов |
| `katalog` | Генератор каталога |
| `snimki` | Снимки первых экрана |
| `proverka-okruzheniya` | Проверка окружения и ключей |
| `uborka-vremennogo` | Уборка временных папок |
| `vyladka-botov` | Починка бота на хостинге |
